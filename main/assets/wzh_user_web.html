使用说明书

使用说明书

认识你的伙伴

我可以通过触摸、动作和声音与你互动。

可以托住身体轻轻摇晃；人体感应可响应附近动静。请勿拉扯头部、尾巴或关节。

充电与开关

请使用产品标配的供电和充电方式。长按电源键开关机；具体接口、指示灯和充电规格以产品标签及随附说明为准。

对话与语音

双击电源键进入或结束对话。联网服务就绪后，可以说唤醒；对方说话时，你也可以开口打断。离线时可尝试说“开心”或“停下”，自由对话需要联网。

连接或更换网络

手机连接设备热点，打开 192.168.4.1。选择家里的 2.4 GHz Wi-Fi 并输入密码。联网后可在详情页选择“更改网络”。热点通道切换时，手机可能需要重新连接。

页面密码

页面密码是 zylz 加设备热点名称最后四位，字母大小写与热点名称一致。例如热点名称以 1A2B 结尾，页面密码为 zylz1A2B。

声音

设备页面支持选择、试听固定音色，以及使用设备录音或上传手机录音创建专属音色。删除专属音色也会删除云端记录；请在安静环境中录制 5–20 秒清晰人声。

动作与保护

设备会根据触摸、姿态和语音作出动作。低电量、温度异常或运动受阻时，保护机制可能暂停动作；请让设备休息，检查供电和周围空间。

常见问题

页面打不开：确认手机连接的是设备热点，再输入 192.168.4.1。连不上路由器：检查密码并确认网络为 2.4 GHz。页面密码错误：检查热点名称最后四位和字母大小写。

恢复出厂

在详情页确认后，设备先删除本机云端复刻音色，再清除已保存的 Wi-Fi，然后重启。删除失败时会保留 Wi-Fi；外置音频库、小智绑定及阿里 Key 保留。

规格、安全与售后

供电、充电、电池、使用环境及保修信息以产品标签和随附保修说明为准。请勿进水、拆卸、强行扳动关节或在无人看护下充电。
