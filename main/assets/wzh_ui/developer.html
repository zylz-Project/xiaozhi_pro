本地 HTTP 接口

点击复制

curl 示例

带 token
curl http://<设备 IP>:8080/api/status

curl -X POST http://<设备 IP>:8080/api/developer/volume \
  -H "Content-Type: application/json" \
  -H "X-Developer-Token: <token>" \
  -d '{"volume":70}'

写接口需要开发者 token；登录成功返回 token，有效期 30 分钟。AP 客户端访问 :8080 直接 403。

403 · 仅限局域网

你正在通过设备热点访问开发者页。为避免普通用户进入，:8080 会拒绝 AP 网段请求。

http://<设备 IP>:8080

把手机连接到与熊猫相同的家庭 Wi-Fi，再使用上面的地址。

原型说明：开发者页按功能齐全优先，视觉密度高于用户页。演示密码 1；状态切换在页面外。OTA、Hub、日志、擦除均为离线模拟，不会访问网络。
