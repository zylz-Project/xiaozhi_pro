`wzh_dinosaur` 是基于 ESP32-S3、ES8311、五路舵机和外部 SPI Flash 默认音频（原理图为 W25N01GV NAND）的恐龙板型。
兼容性标识和构建名按仓库规则使用 `wzh-dinosaur`（标识不允许下划线）。

## 模式

- 在线：设备处于 `connecting`、`listening`、`speaking` 或录音测试状态，即正在建立会话、听用户说话或播放回复。本地声音会暂停；服务端的 `llm.emotion` 和 `self.dinosaur.react_to_user_emotion` 负责驱动情绪动作。
- 离线：设备没有进行语音交互时，包括 Wi-Fi 已连接但处于 `idle` 待机的情况。本地安静等待互动，收到有效事件后再按请求执行动作和已有声音。

因此，“在线/离线”描述的是恐龙当前是否正在对话，而不是单纯描述 Wi-Fi 是否连接。切入在线对话时会停止并清理尚未播完的本地声音，避免干扰麦克风和服务端 TTS。

本板型未移植旧工程的固定 SSID 和 HTTP 上传服务；当前音频目录、播放、Audio Hub 绑定同步与网络下载由共享 WZH 层承担。外部 Flash 中没有有效 `PNDA` TOC 时，离线动作仍可运行，但不播放本地声音。

## 情绪到动作

| 模型情绪 | 动作 |
| --- | --- |
| happy / laughing / winking | happy |
| loving / embarrassed / relaxed | affection |
| sad / crying / angry / fearful | listen（温和倾听）；sleepy 单独表示困倦 |
| confident / cool | proud |
| surprised / shocked | startled |
| thinking / confused / curious | discover |
| neutral 或未知 | listen |

服务端模型提供主要情绪语义；固件额外对用户转写和宠物回答句子做保守关键词兜底，不将该规则称为完整情绪识别。若要利用音色、语速等声学信息，需要服务端 ASR/情绪模型把结果提供给对话模型；设备端目前上传的是语音，不在本地运行情绪神经网络。

## 按键行为

- 模拟电源键双击：开启/关闭对话。
- 模拟电源键长按约 1.5 秒：关闭电源锁存。
- GPIO0 单击：配网状态下进入配网，正常状态下同样可切换对话。
- GPIO0 双击：停止/恢复宠物活动；停止或休息不会被普通情绪、自主事件解除。

## 触摸交互

四路触摸电极沿用 `testBoard_wifiweb` 的 IO5（ADC1_CH4）R-2R 接法：每 20 ms 连读
3 次取中值，按原工程 0～3150 mV 的 16 档阈值解码 SW1～SW4，连续 5 个样本
（约 100 ms）一致才发布。单点触摸触发 `affection`，同时触摸任意两点及以上触发
`happy`；在线对话期间只做动作，离线时可同时播放对应本地声音。稳定编码、电压和
按下/释放位掩码会写入串口日志，便于真机校准。

## 配网

开机没有已保存 WiFi 时，开启自配热点 `Dino-XXXX`，手机连接后访问
`192.168.4.1` 使用自定义配网页（扫描 WiFi、输入密码、一键连接），
不再使用小智默认配网页。凭据写入小智 WifiManager，保存后自动连接。

## 扬声器音频随动

五轴方向已由用户于 2026-09-13 确认：IO15 头部和 IO16 颈左右均为 0=右、180=左；
IO17 颈上下为 0=仰天、180=低头；IO8 尾上下为 180=上、55=最低允许值；
IO18 尾左右为 0=左、180=右。默认姿态不变，不交换引脚。
新增 `discover-canopy` 高低巡视、`happy-invite` 探身招呼和 `eat-graze` 贴地取食。
取食包含正面 IO17=180 的停留，再换侧慢嚼、抬头确认；深低头时声音抬头叠加逐渐
减弱，到 180 时归零，避免咀嚼声把头拉起来。明确指定的 0/180 落点不参与随机缩幅。
新动作各帧同步、舒缓，保留旧动作及原触发间隔；仍需实机验证组合姿态的干涉和电流。

本轮 `stories-v4` 增加亲近后回看用户、侧耳后再次确认，以及短吼轻收声和长吼高位
弧线四套变化。随机放大的目标先限制到实际允许角度再插值，减少极限位的截断停顿；
生命微动在关键帧两端平滑淡入淡出，短帧减弱微动，避免每次停顿额外快速扭一下。
不改变自动触发间隔、待机中位和声音 PCM 随动链路。

离线自主表演以外部 Flash 音频为主线：先选中实际要播放的文件，再根据文件名关键词
和时长判断 `discover/affection/happy/proud/eat/listen/startled/sleepy`，等该文件真正开始
播放后同步起动作。完整动作库现有 24 套，1～4.2 秒声音另有 24 套专属紧凑编舞，
再加正面长啸、短吼回应、轻微侧仰、高位扫视、二次回应、轻收声和高位弧线 7 套怒吼，共 55 套声音表演。
所有“叫声音效合集 (N)”、怒吼、长啸、咆哮或 `roar` 都按时长进入怒吼库：每套先把
颈俯仰明显抬到 0～4°，再加入有限且平衡的横向细节；不随机镜像，也不叠加额外横向
音频偏移，避免总朝同一侧扭头。声音强弱主要加强仰头和抬尾。同一行为族不会连续
复读同一轨迹。较长声音使用完整编舞，并在
声音较长时按时长进一步放慢拉伸；原有完整动作数据不被替换。

动作引擎直接使用 AudioService 扬声器输出端的真实 PCM 响度，因此在线对话 TTS、
外部 Flash 本地声音和系统提示音都会带动颈部、头部和尾巴。响度决定动作幅度，
重音形成柔和抬头；五轴同步响应同一份包络，动作采用低通和平缓相位变化，
不跟随单个音节高速抽动。Flash 主体表演期间会适度提高包络表现力：声音越饱满，
颈、头和尾的同步姿态越舒展；轻声时自然收住。

新增短声动作参考旧恐龙工程的仰望追踪、害羞贴近、空间画圆、威严守望、取食回看、
高空聆听、低伏躲避和绕身入睡，并重新编排为五轴同步动作。旧工程只有尾上下使用
反向内部角度，移植时按 `实际尾上下角度 = 180 - 旧动作角度` 换算，其余四轴不反向。

待机呼吸约 12 秒一轮：缓慢吸气、缓慢呼气，最后约 4 秒回到板级默认中位并停顿。
偶尔出现的观察偏姿只保持约 3～5 秒，随后回中约 9～15 秒，因此默认状态以中位为主。
完整动作、生命脉冲和语音身体指令共用舒缓限速：每段实际位移至少 420 ms，
最快轴平均不超过约 80 度/秒。连续同向的关键帧使用无过冲的单调 Hermite
轨迹穿过中间姿态，不再每帧分别刹停；只在反向、定格和最终收势自然减速。
自主动作与生命脉冲的触发间隔保持产品原有节奏，
“慢”只作用于动作本身，不额外延长两次动作之间的等待时间。

基础姿态与声音/生命微动分层保存，输出偏移不会再写回下一帧；镜像只作用于本帧
新指定的侧向目标，`kKeep` 轴不会被二次翻转。动作中的生命微动在每段中部展开，
到关键落点自动归零，因此待机默认姿态能准确回中，不再持续偏向一侧。

待机生命脉冲包含观察、尾摆、嗅闻、精神一振、好奇侧头、友好招呼、二次确认和
全身舒展八种小表情；相邻两次不会重复同一种。新增小表情不改动原有完整动作，
同一关键帧中的关节仍然同步开始、同步到达，并在结束后自然回中。

怒吼起手采用 `roar-onset-v3`：七套编舞的首帧都是
`{neck_tilt=0, neck_lean=90, head_turn=90, tail_lr=90}`，从默认姿态约 900 ms
到达，尾巴同时抬起。长音频只拉伸后续主体编舞，回中收势单独计时；后续侧仰采用
头部反向视线补偿和尾巴配重。每个怒吼落点输出 `Roar pose` 日志，记录最终 PWM
目标角度；日志是软件指令，不是舵机反馈。

如果仰头仍表现为向左，可显式调用 `self.dinosaur.test_servo`，参数
`{"gpio":17}`。测试先回默认姿态，再只让 IO17 按 70→45→70→95→70 缓慢运动，
期间关闭音频和生命偏移。参考装配预期先仰、后俯；也支持分别测试 IO16、IO15、
IO8、IO18。此测试不会开机自动执行。若 IO17 单轴测试实际带动左右轴，需要核对
实机接线/机构与参考工程的差异，不能仅靠代码注释认定方向已正确。

## 构建

```sh
python3 scripts/build.py wzh_dinosaur --name wzh-dinosaur
```

构建成功只能验证软件集成；首次烧录后仍需检查 IO5 的 16 档触摸电压、电源锁存、
电池分压、五路舵机方向和机械限位、ES8311 录放音，以及外部 Flash 默认音频。

## 感应、离线关键词与动作保护

已接入 IO41 人体感应、SC7A20H 姿态与现有 IO5 触摸，默认启用中文离线动作关键词。
新增欠压禁动/关机、ESP32 芯片温度保护和舵机连续通电超时；动作后关闭 PWM 与 IO4，
安静间隔释放舵机。原理图无舵机温度/电流反馈，不能直接测得真实堵转或绕组过热。
接线、命令表、阈值和真机验收见[共享说明](../../../docs/wzh_sensing_and_protection.md)。
