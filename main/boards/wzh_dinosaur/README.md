# 恐龙 · 小龙

板型标识为 `wzh-dinosaur`，使用 ESP32-S3、ES8311、一路 180° 头部舵机和四路 270° 颈尾舵机。配网热点为 `Dino-XXXX`，设备页面在 `http://192.168.4.1`。待机唤醒词为“小龙小龙”。[三款快速上手](../../../docs/wzh/product/family_quickstart.md)

## 装配和角度

以下五轴方向由用户在 2026-09-13 确认。角度表使用动作库的逻辑坐标。

| 轴 | GPIO | 默认角 | 软件范围 | 方向 |
| --- | --- | --- | --- | --- |
| 颈俯仰 | IO17 | 70° | 0–180° | 0° 仰天，180° 低头 |
| 颈侧倾 | IO16 | 90° | 0–180° | 0° 向右，180° 向左 |
| 头转向 | IO15 | 90° | 0–180° | 0° 向右，180° 向左 |
| 尾上下 | IO8 | 90° | 55–180° | 55° 最低，180° 最高 |
| 尾左右 | IO18 | 90° | 0–180° | 0° 向左，180° 向右 |

颈尾四轴的逻辑 0°、90°、180° 对应标称物理 35°、135°、235°，脉宽约 759、1500、2241 µs。尾上下逻辑 55° 对应物理约 96.1°。IO15 使用 180° 校准。舵机电源为 IO4，安装时校准中位、脉宽及组合动作的机械间隙。[硬件复核](../../../docs/wzh/hardware/hardware_review.md)

装配诊断可显式调用 `self.dinosaur.test_servo(gpio)`。例如 IO17 单轴依次走逻辑 70°→45°→70°→95°→70°，预期先仰后俯。诊断由动作任务执行，并关闭声音和生命微动叠加。

## Wi-Fi 与 ML307

唯一发布变体 `wzh-dinosaur-270-servo` 同时支持 ML307 AT 和 Wi-Fi。已有 Wi-Fi 凭据且上次手动选择 Wi-Fi 时直接连接 Wi-Fi。其余情况下，开机探测到模组后先选择 4G。模组探测无应答时使用 Wi-Fi。若 4G 在约 15 秒内仍未就绪或断线后未恢复，有已保存的 Wi-Fi 才自动切换并播报。没有 Wi-Fi 凭据时，设备保留 4G 重试并提示配网。自动切换保留手动偏好，页面分别显示模组、联网和语音服务状态。[运行架构](XIAOZHI_RUNTIME.md)

ESP32 TX=IO12 接模块 RX，ESP32 RX=IO11 接模块 TX。主板 JP1 提供 +5V，ML307 裸模组的供电及 UART 电平以外接板规格为准。用户实机读到 `ML307C`、固件 `2503070906`，照片确认 `ML307C-DL-CN`。较早的 PPP 试验中 SIM、网络注册和 PDP 成功，`ATD*99#` 返回 `ERROR`。当前固件使用 AT 网络路径。[接线、实机记录与 4G 验收](../../../docs/wzh/hardware/dinosaur_ml307_2026-11-15.md)

## 触摸与动作

SW1 到 SW4 依次为头、胸前、靠脖子的背部、靠尾巴的背部。SW3→SW4 的顺摸采用温和回应，SW4→SW3 的逆摸采用活泼回应，单独触摸两个背部触点也分别有回应。对话中的触摸位置和顺逆方向在语音空档送入当前会话。

普通未配套录音在 4.2 秒及以内采用紧凑编舞。吼叫使用时长匹配的独立动作库，覆盖正面仰吼、侧向下探和高低扫视。手调吼叫录音保留原始轨迹，并与选中的吼叫动作合成。关节命令只驱动指定轴。[动作库与展示节奏](../../../docs/wzh/motion/motion_libraries.md)

## 构建与验收

使用 ESP-IDF v6.0.2。运行日志通过 USB Serial/JTAG 输出，ML307 继续使用 IO12 和 IO11 的 UART。

```sh
python3 scripts/build.py wzh_dinosaur --name wzh-dinosaur-270-servo
```

实机重点复核五轴方向与极限位、外壳干涉、带载电流、SW3/SW4 顺逆摸、ML307 冷启动与 Wi-Fi 回退、主动切网及弱信号对话、实际麦克风电平和关键词打断。[产品验收表](../../../docs/wzh/product/product_acceptance.md) · [ES8311 麦克风增益](ES8311_MIC_GAIN.md)
