# WZH 触摸与拿起互动反馈修正

2026-10-16 后续动作更新：三款扩大行程、温和偏移调整为 60%，小熊猫修正关键帧压幅，爬爬熊猫加入有限爬行；动作参数与验证以[当前动作说明](wzh_large_motion_2026-10-16.md)为准。

后续修正：按用户要求，互动声音只使用已有外置 Flash 录音；已撤下本文早期版本的合成短音。详见[当前外置音频说明](wzh_flash_interaction_2026-10-16.md)。

## 用户日志能确认的情况

2026-10-16 的爬爬熊猫运行日志显示四个单触点分别约为 200、413、816、1638mV，
都被正确识别。多数触摸在稳定编码发布后约 20ms 就启动了动作。例如：

```text
PandaPower: [TOUCH] code=0x02 voltage=413mV
WzhAudioPlayer: Playing offline sound: 熊猫撒娇声音
PandaMotion: clip=affection_ask_up
```

当时的问题包括：所有单触点进入同一个 affection 行为族，重复请求可能在 1.2 秒内合并；
动作与声音反馈没有区分触点，回应音受 12 秒预算限制；拿起、摇晃进入温和状态后本地声音被禁止，
而加速度事件原先只在舵机未通电时触发。用户直接感觉为“摸了没有明确回应”。

用户随后提供的开机片段包含 `mpu6050`、`MPU-6050 未检测到` 和 IO43/44 上扫描到 0 个设备。
该片段与当前本项目的 `WzhSensors` / SC7A20H 实现不符，不能视为当前 SC7A20H 初始化成功的证据。
0 个 I2C 应答还涉及固件版本、芯片供电、接线和实装型号，不能仅靠改日志名称判定修复。

## 本次实际改动

### 爬爬熊猫的直接触摸

| 输入 | 回应 |
| --- | --- |
| SW1 / code 0x01 | 头部短回应 |
| SW2 / code 0x02 | 左前肢短回应 |
| SW3 / code 0x04 | 右前肢短回应 |
| SW4 / code 0x08 | 双前肢拥抱式回应 |
| 同一触点连续轻触或组合触摸 | 更活泼的短回应 |
| 持续按住约 1.2 秒 | 温和转头回应，持续接触保持温和状态 |
| 长按后松开 | 观察式短回应 |

SW1～SW4 的身体安装位置以实物为准；软件没有把未知位置命名为“头部触点”或“背部触点”。

触摸作为明确的用户输入进入请求队列，不再与被动人体感应共用低优先级。
编码变化时立即提交一次请求，耗时声音解码和舵机插值仍留在各自工作任务。
两款熊猫新增 11 个固定方向的两关键帧互动剪辑，区别于原来的长表演；原有动作库、身体指令、
最终行程和速度限制保留。恐龙沿用对应身体动作并获得同样的输入分流和短音反馈。

### 声音反馈

触摸、拿起、摇晃等互动按实际外置 Flash 目录匹配亲近、开心、好奇或受惊声音。
有其他动物声音时跳过上一条，再按匹配程度选声；目录为空时只给动作回应。
按完整原文件解码，实际时长由已有素材和播放是否被新请求中断决定，不再使用新增的合成短音。

明确互动的声音单独使用约 650ms 的最小启动间隔，温和状态允许声音回应。
其他普通表演声音仍受原有 12 秒预算控制，安静模式不播放互动声音；停止和休息不会被触摸解除。
在线聊天期间触摸与姿态使用动作回应，保持在线语音的播放优先级。

声音队列携带播放代次和选中文件的元数据，停止或切换会话后丢弃旧请求，目录重排不改变已选文件。
声音仍复用 AudioService、OGG/Opus 解码和 ES8311，不新增录音或 I2S 链路。

### 加速度计与识别

当前期望硬件是 SC7A20H，使用 I2C1 SDA=43、SCL=44，探测 0x18/0x19；ES8311 保持独立 I2C0。
初始化打印实际地址、WHO_AM_I 与 VERSION，保留型号检查和寄存器回读。
总线降低为 100kHz 并启用辅助内部上拉；原板外部上拉仍应按原理图装配。

初始化失败每 5 秒重试，连续读失败后重新探测；已有落体保护保留到有效稳定数据恢复。
运行时每约 3 秒打印三轴 mg、模长、变化量、舵机供电和保护位。
事件日志同时打印 `picked_up/shaken/flipped/settled` 和 `accepted`，可区分“没读到”与“读到但被拒绝”。

拿起估计结合加速度变化和持续倾斜，摇晃采用连续样本确认；舵机通电期间仍识别明显的人为搬动，
同时对小幅自身振动做过滤。事件只在实际被接受后消耗冷却，被拒绝的短事件有有限重试窗口。
拿起和摇晃不会改成每次都执行同一个撒娇表演。

加速度计不能直接测高度、手的接触或精确落地；完全平稳、保持水平的搬运不保证识别。
“放稳”是稳定后的估计事件。落体保护独立于互动识别，严重摇动触发保护时仍优先释放舵机。

## 如何确认烧录的是本次固件

开机应出现：

```text
WzhSensors: WZH feedback-v2; expected SC7A20H accelerometer, I2C1 SDA=43 SCL=44, addresses=0x18/0x19
WzhSensors: SC7A20H address=0x18 WHO_AM_I=0x11 VERSION=0x28
```

如果一直出现 `SC7A20H unavailable`，应先根据实际电路检查该芯片的供电、地址及 SDA/SCL，
并确认传感器线路没有同时用作 UART0。不要将 `mpu6050` 的旧测试日志与本次小智运行日志混用。

触摸后可检查：

```text
PandaMotion: Interaction=touch2 accepted
PandaMotion: clip=ack_touch2 ...
WzhAudioPlayer: Interaction=touch2 external Flash sound: <实际文件名>
```
