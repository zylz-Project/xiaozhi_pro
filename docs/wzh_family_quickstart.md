# AI 陪伴宠物家用上手说明

适用：爬爬熊猫、恐龙、摇尾小熊猫。更新：2026-10-19。

## 第一次玩

1. 开机后听到开机提示。动作还需等待电量检测就绪，通常约 17 秒；电量不足会继续限制动作。
2. 先轻触一个触点，等它完成回应；换一个触点，观察不同部位和动作变化。
3. 可拿起、摇晃或翻转来互动。等它完成当前动作再进行下一轮，不要强扳舵机或拉扯尾巴。
4. 对它说“开心”“撒娇”“吃东西”“摇摇头”等固定口令，即使没有网络也能控制对应动作。
5. 想聊天、听故事或玩问答，先完成 Wi-Fi 与平台激活，双击电源键或说对应唤醒词，听到对话提示后提问。再次双击可退出对话。

| 产品 | 唤醒词 | 联网后可以这样开场 |
| --- | --- | --- |
| 爬爬熊猫 | 你好小安 | 今天陪我玩个猜谜游戏吧。 |
| 恐龙 | 小龙小龙 | 讲一个小恐龙交朋友的故事吧。 |
| 摇尾小熊猫 | 你好星宝 | 今天我有点不开心，陪我聊一会儿。 |

没有网络时，触摸、姿态、人体新靠近及固定语音口令仍可玩；自由聊天、故事生成和开放问答需要联网服务。

## 怎么互动更有意思

- 换着触摸不同触点，或同时触摸两点；同一点连续轻触三次，会触发更活泼的回应。
- 保持接触约 1.2 秒，它会温和一些；一直按着不会一直重启同一段动作。
- 真实有人重新靠近时，它可以无声观察；一直待在附近不会按时间重复表演。
- 一次回应结束后，它会释放舵机。正常待机且无互动时，空闲约2秒后会自主播放下一段配套音画；需要持续安静时可使用下面的口令。
- 联网聊天时可以请求“向左看”“向右看”。爬爬熊猫还可以请求“爬一爬”“双手一起爬”；这些爬行短语属于联网语义能力，不在当前离线词表内。

交替爬行约每 0.8 秒一周期、执行 6 周期；双手爬行每 1.2 秒一周期、执行 4 周期，随后收尾释放。

爬爬熊猫本轮增加头爪配合与爬行回看，左右挥爪按指令执行。全部动作的节奏可查看[本地预览](../dist/wzh-crawl-lively-20261016/motion-preview.html)。

两款熊猫头部可左右转动；恐龙还有颈部抬低头动作。爬行效果与地面、毛绒和装配有关，没有自动导航能力。

## 想让它安静下来

| 说什么 | 会怎样 |
| --- | --- |
| 安静 | 中断当前互动，保留较温和的无声触摸回应；普通本地叫声关闭。 |
| 停下／别动 | 停止当前声音和动作，保持停止，普通触摸不重新开动。 |
| 睡觉／晚安 | 持续休息，等待明确恢复，不会过一会儿自己醒来表演。 |
| 醒醒 | 恢复本地互动，并给一次恢复回应。 |
| 对应产品唤醒词 | 恢复可互动状态；联网就绪后继续进入小智对话。 |

扬声器播放时，“停下、安静、晚安”等停止类口令仍提供识别入口，实际识别受环境影响。其他离线动作口令在播放期间会暂缓响应；也可以等它说完再说。

电源键双击进入对话，再次双击退出；连接中、收音中和回复中都可以退出。长按约1.5秒保留原有关机流程。如果外壳提供BOOT功能键，它也使用双击进入／退出；正常运行时单击不启动对话，启动及配网状态保留配网入口。详见[双击操作与播放衔接说明](wzh_double_click_conversation_2026-10-19.md)。

“晚安”和“安静”不是物理断麦。休息时仍需监听恢复口令；需要关闭设备时请关机。

## 没有回应时

先确认已过开机检测阶段、宠物不处于停止或休息、电量足够。刚做完动作时，它会短暂确认自己已站稳，再接收下一轮姿态互动。启动时手指一直按住触点，须先松开再触摸。

动作有回应但没声音，可能是安静状态、正在对话、原录音未播完、声音更新中，或外置存储没有合适录音。声音更新会避让日常互动，维护时仍可能暂时无新叫声；不要为了测试反复按住电源键。

正常待机的间隔音画是展示功能。如果已说“停下”或“晚安”仍自动表演，或出现持续异常动作，应保存固件版本及对应日志交给维护者。固件的`Input=`行可以标明触摸、姿态、人体或离线口令来源。

## 家庭配置建议

可让角色侧重陪伴、故事和启发式提问，回答尽量短，让孩子有机会接话。遇到不知道的问题坦诚说明；情绪低落时温和倾听，并鼓励联系身边信任的人。角色要清楚表明自己是 AI 宠物，不制造排他关系。

声音、内容、记忆和语音数据保存取决于实际接入的服务。家长设置、内容策略和删除记录需要在相应平台确认；当前固件没有独立家长 App、课程进度系统或物理麦克风隐私开关。
