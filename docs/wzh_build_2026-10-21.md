## 编译修正和验证

芯片编译发现 `UserPairMotion::Begin()` 的 `std::max({...})` 混用了 `uint32_t` 与 `unsigned int`。本机主机编译时二者相同，Xtensa 工具链下 `uint32_t` 是不同整数类型，导致模板推导失败。已显式指定 `std::max<uint32_t>`，保留原来的时长选择行为。

修正后重新运行全部 179 项主机测试并全部通过，三款均经规范入口构建：

```sh
source /home/wzh/.espressif/v6.0.1/esp-idf/export.sh
python3 scripts/build.py wzh_dinosaur --name wzh-dinosaur --zip
python3 scripts/build.py wzh_crawlPanda --name wzh-crawlpanda --zip
python3 scripts/build.py wzh_tailRedPanda --name wzh-tailredpanda --zip
```

完整构建日志分别位于 `/tmp/wzh-build-dinosaur-20261021-retry1.log`、`/tmp/wzh-build-crawlpanda-20261021.log`、`/tmp/wzh-build-tailredpanda-20261021.log`。测试日志为 `/tmp/wzh-build-host-tests-final-20261021.log`。分产品 app、ELF、assets、配置、打包字节验证及旧包备份暂存于 `/tmp/wzh-compiled-20261021/`。

构建日志有 SDK/组件已有的 Kconfig 默认值和可选依赖提示，三款最终均成功退出，没有为绕过这些提示修改 SDK 或 vendor。编译通过不能代替实机的关节方向、机械间隙、识别率、供电采样和温度保护验证。
