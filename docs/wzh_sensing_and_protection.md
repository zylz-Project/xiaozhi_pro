## 感应与交互

| 能力 | 实现与行为 |
| --- | --- |
| 人体感应 | IO41，高电平有人；3 个 20ms 样本确认变化。上电前 10s 抑制招呼；确认有人后提交 `discover`。 |
| 触摸 | TTP224 四路输出经 R-2R 接 IO5/ADC1_CH4；原有 3 次中值、5 样本稳定判定保留。单点 `affection`，多点 `happy`。 |
| 姿态 | SC7A20H，SDA=IO43、SCL=IO44；独立 I2C1，不占 ES8311 的 I2C0。探测 0x18/0x19 并核对 ID、版本和配置回读；±4g、12bit、100Hz。 |
| 拿起/摇晃/翻面 | 用三轴加速度变化与六面重力方向判断；采用温和回应；普通振动在舵机释放时识别，新增相对静置重力的大角度持续倾斜检测可在通电时生效。 |
| 自由落体 | 连续 3 个样本低于 250mg 时立即释放舵机；连续 25 个有效近 1g 样本后解除该锁。 |

2026-10-15：人体和姿态采用独立冷却；人体招呼待预热、电池就绪并被动作任务成功接收后才消耗事件。
触摸支持连续轻触、约1.2秒长按和释放回应；配网/激活允许显式本地交互，升级/录音测试等维护态禁动。
完整状态、幅度和感应估计边界见[宠物交互说明](wzh_pet_interaction.md)。
姿态读取失败时标记数据无效，降低重试频率，保留已经触发的落体保护直到有效数据恢复。
传感器不存在不阻止整机启动。

SC7A20H 是加速度计，不能测量 Yaw 或角速度。只有加速度模长在 700～1300mg 时
Pitch/Roll 有效；六面方向按芯片坐标报告，不能未经装配校准就称为机身正面/倒置。

MCP `self.panda.get_sensors` / `self.dinosaur.get_sensors` 提供人体状态、三轴 mg、
角度及有效标志、六面方向、舵机电源状态和保护位。
`motion_faults` 位：1=低电量，2=芯片过热，4=落体，8=关机，16=连续通电超时冷却，32=电池采样尚未就绪，64=宠物停止/休息，128=维护禁动，256=运动更新超时。

| 向右看 | look_right |

| 醒醒 | 恢复正常陪伴 |

识别器将结果作为 `local:*` 事件送给主事件循环，`Board::HandleLocalVoiceCommand`
消费事件，再重新开启识别，不建立 WebSocket/MQTT 会话；其他板默认不消费事件。
本款专用唤醒词同时明确恢复宠物活动，并在网络就绪时发起在线对话；普通本地动作不关闭会话；停止、安静和休息会中断当前会话。
编译配置选择 AFE WakeNet 或自定义 MultiNet 唤醒模式时均可启用上述命令；显式关闭唤醒识别时也会关闭离线关键词。

首次烧录及本次切换 WakeNet 时要同时更新 assets，不能仅刷 app。离线命令阈值由
`WZH_OFFLINE_COMMAND_THRESHOLD` 配置，默认 50%，不影响 WakeNet 阈值。需要在实际麦克风、
扬声器音量、机械噪声环境下评估误触发与漏识别；关键词属于有限命令识别，不是离线大模型。

## 电池、温度和舵机保护

- 2026-10-21 三款已启用常规电池参数，普通低电也使用时间中值和连续确认；电量与页面电压改为静置更新。源码更新，未编译／未烧录。完整时序与验证见[本轮说明](wzh_battery_rest_2026-10-21.md)。
- 电池分压仍为 IO3/ADC1_CH2、2:1，约每秒丢弃切换后的两次转换，再取 32 次读数，去掉最高／最低各四次后平均。普通保护取三轮时间中值，慢速 IIR 仅用于静置显示。采样失败会打断连续计数，不会把读取错误当成零电压。
- 分压电路的 340kΩ/340kΩ 和 22µF 电容约有 3.74s 时间常数；启动先禁止舵机，
  等待约 15s，再取得五轮有效读数建立中值及确认序列，正常约 19s 解除采样等待锁。ADC 读取失败重新锁定，
  连续有效读数恢复后才允许动作。
- 每个板子的 `config.h` 用 `BATTERY_DEMO_MODE` 选择整套阈值：
  - `1`（旧演示值，当前未启用）：`BATTERY_LOW_MV=3100`、`BATTERY_RECOVER_MV=3250`、
    `BATTERY_CRITICAL_MV=2900`。
  - `0`（当前常规保护）：`BATTERY_LOW_MV=3300`、`BATTERY_RECOVER_MV=3400`、
    `BATTERY_CRITICAL_MV=3000`。
- 连续 3 次时间中值 ≤`BATTERY_LOW_MV`：禁用所有舵机输出，暂停本地动作音频并清空待执行动作。
  满足静置条件且连续 3 次时间中值 ≥`BATTERY_RECOVER_MV` 才恢复，当前常规参数为 100mV 滞回。
- 连续 3 次 ≤`BATTERY_CRITICAL_MV`：立即断开舵机电源和整机锁存，不播放关机提示、不再驱动回中。
  此功能是固件欠压保护，充放电硬件保护仍由电源电路承担。
- 短暂负载压降由时间中值及连续确认过滤，持续低压仍可在动作期间触发保护。舵机断电后要静置确认回升到恢复阈值才允许动作；临近阈值时仍可能出现保护与恢复交替。
- 2026-10-21 按用户展示要求，三款 ESP32-S3 内置温度传感器 ≥90°C 时禁止舵机，≤85°C 后解除过热限制，85～90°C 之间保持原状态；其他保护仍独立生效。源码已更新，未编译／未烧录。
  测量对象是 ESP32 芯片，不是舵机绕组、电池或外壳。
- 三产品统一通过 `ServoOutput` 写 PWM 和 IO4 电源。故障置位与 PWM 更新共用互斥锁，
  避免另一个任务重新给被保护的舵机通电。电源任务每轮独立检查通电预算。
- 完整动作、身体动作和生命脉冲结束后释放舵机；熊猫在最终落点保留约 300ms 到位时间。
  安静间隔不再持续写呼吸/微动 PWM。播放声音时保留音频随动，下一次动作恢复 50Hz 输出。
- 连续通电最多 60s，之后至少 5s 断电冷却；功率预算使用可跨毫秒计数器回绕的计时。
- 正常长按关机通过动作任务请求默认姿态，然后锁定舵机输出；欠压或其他保护已经生效时
  不尝试再次驱动回中。外部回调不直接修改插值状态。

原理图没有舵机电流检测、位置反馈或舵机温度探头。动作后释放和通电超时能减少持续
顶住/发热，但不能判断动作中真实堵转，也不能承诺舵机过热检测。需要即时堵转/绕组
过热检测时，应增加电流或位置反馈及温度硬件，并提供各产品实际校准阈值。
释放后机构可能在重力或外力下移动，重新通电时仍需实机确认无冲击和掉落风险。
