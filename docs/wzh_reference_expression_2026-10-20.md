# 三款萌宠的音画表现与参考例程融合（2026-10-20）

本轮为**源码更新，按用户要求未编译固件、未打包、未烧录**。`releases/` 里的安装包仍是上一轮版本；已有固件清单不代表本文的新代码。

## 恐龙为什么参考例程更有感染力

对照用户指定的 `final/newWebServer_Project/dinosaur/main/auto_run.cc` 与 `auto_run_data.cc`，关键不只是动作表：整段表演还会选择颈部宽弧、空间环绕、前探、视线关注和尾巴配重等风格。

此前这 29 段参考动作已经在动作库中，但优先播放手调音画包时主要执行录制轨迹；通用音画播放也主要按声音种类生成目标。参考库里的表演关系没有充分参与这些最常见的播放路径。

现在恐龙每段本地音频开始实际发声后，按声音含义抽取参考片段：

| 声音 | 参考动作组 |
|---|---|
| 普通叫声 | 发现、观察 |
| 撒娇、哀鸣 | 亲近、靠近、轻蹭 |
| 开心、伸展 | 幼龙展示、宽扫、空间环绕、追尾 |
| 咀嚼 | 闻食、取食、抬眼确认 |
| 脚步、寻找 | 定位、追踪、二次确认、观察高处 |
| 喷嚏 | 受惊、避让、恢复 |
| 困倦 | 低头侧靠、点头、寻找睡姿 |
| 长鸣、吼声 | 威风鸣叫；通用吼声继续使用专用仰天动作池 |

声音先选定，动作再使用该声音的播放时钟。手调包仍作为主要轨迹，参考动作最多占 34% 的混合权重，再按声音强度和进出场包络收敛；通用非吼声音效最多占 52%。同一关键帧五轴共用进度，物理轴序、方向和机械限位保留。

逐项核对了用户此次给出的参考工程：**29 段原始关键帧的角度和时长全部匹配**。只有旧格式尾上下转换为 `max(55, 180 - legacy_tail_ud)`，并沿用末尾归中帧。核对证据见 [参考源清单](wzh_reference_expression_source_2026-10-20.json)。

## 三款各自的表达

- **大熊猫**：单爪邀请、换爪回应、抬爪贴近脸侧、双爪招呼等组合。头部做看向、停留、确认，身体动作保持独立变化。爬行牵引仍由原步态负责。
- **小熊猫**：宽摆、上下左右圆弧、高翘停留、舒展回落四类尾姿；与转头配合。保留坐姿 `90/90/150`，动作中的尾上下仍能明显上翘。
- **恐龙**：让真实参考片段参与常用本地音画路径，再组合宽弧、环绕、S 形、前探，以及宽扫、画圆、高位和配重尾姿。部分脚步录制的颈俯仰接近贴地取食，现将该轴相对 70° 的偏移调整为原来的 42%，侧向主动作继续保留。

52 套手调配套均增加 **16 种随机表达**，每个音频独立洗牌，轮内抽完且跨轮不紧接重复。配套音频和原 Flash 音频拥有独立的选择状态，64 个来源交替播放也不会把别的音频的变化池重置。参考片段也有独立的轮换袋。

这些变化在开始表演时选定；播放中沿同一条连续轨迹运行，不在每个舵机刷新周期重新抽角度。

## 修掉录制轨迹里隐藏的急转

部分手调包在 20～60 ms 内变化很大。上一轮的稀疏平滑采样仍可能漏过这些变化，导致目标速度尖峰，舵机不断追赶。

现在对连续曲线做正权重三角窗口积分，分段积分 Hermite／五次缓动，并在窗口顶点处分段。窗口随产品和总时长调整：大熊猫最高 ±420 ms，小熊猫 ±450 ms，恐龙 ±600 ms。五轴使用同一时间窗口，轨迹保持在原有物理角度范围内；随后再添加有边界的整段表达。

进场根据距离缓起，结束仍使用独立的五次曲线柔和归中。短音效给一个可见、可完成的动作：大熊猫动作主体至少 1000 ms，小熊猫至少 1200 ms，恐龙至少 1400 ms；较长录音保持 `max(录音时长, 录制动作时长)`。因此极短声音的动作可以适度延续到声音结束后，避免把大幅动作压缩成急甩。

单次基础配套审计的最大目标速度如下（不叠加恐龙参考片段）。完整参考组合另外进行了下述 832 条轨迹检查。这里是**软件目标曲线**，不是带载舵机的实测速度；实际输出仍有原来的 400°/s 同步限速。

| 产品 | 本轮前 | 本轮后 | 柔和归中峰值上限 |
|---|---:|---:|---:|
| 大熊猫 | 1388°/s | 343°/s | 100°/s |
| 小熊猫 | 914°/s | 397°/s | 75°/s |
| 恐龙 | 1118°/s | 331°/s | 65°/s |

审计中的动作范围仍有明显大幅度：大熊猫头部约 19～159°，小熊猫尾上下可到 10°，恐龙颈俯仰仍可到 0°，侧倾约 0～176°。具体每段声音和随机风格不同，并非所有声音都扫满行程。

## 声音和对话的联系

每个配套包使用自身录音重新提取的 PCM 包络，100 ms 一点。52 个包合计增加 1835 字节的包络值，并保留音频 SHA 核验；运行时读取常量，不在音频任务中重新分析或申请完整音频缓存。

本地动作的声音强弱参考平滑包络；熊猫头部的关注方向按完整段落变化。小智对话的头部也改为一句话内的“看向—停留—再确认—回正”，并使用单独的缓慢能量通道，避免将转头轴当成随音节点头的轴。对话中小熊猫增加几类连续尾弧，爪部、尾巴仍响应真实扬声器 PCM。

小智原生云端对话、双击开关对话、触摸优先、安静归中及保护断电继续沿用。普通启动和播放保持现有的手动 Audio Hub 策略。

## 本轮验证与查看方式

- 170 项主机测试通过，覆盖现有会话切换、保护、抢占、原步态、退出归中等路径。
- 65 个通用录音 × 16 次回放，共 1040 条通用轨迹，通过时长、机械限位、峰值速度和归中检查；其中通用恐龙吼声保留专用 3／4 段候选池。
- 52 个手调录音 × 16 种变化，共 832 条配套轨迹，以 5 ms 间隔检查：有限值、限位、目标速度低于 500°/s、独立柔和归中，以及按 0.1° 采样的实际轨迹互不相同。
- 29 个真实参考片段各检查 16 次混合，验证 `kKeep`、连续衔接和物理角度。
- 基础配套的更细审计及返回残差见 [52 套审计数据](wzh_user_pair_motion_audit_2026-10-20.json)。
