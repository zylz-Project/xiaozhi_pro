后续编译验证：三款已在 2026-10-21 编译通过并生成含匹配识别资源的固件包，未烧录。见[最新编译结果](wzh_build_2026-10-21.md)。下方为源码修改阶段的实现记录。

## 直接使用

本地待机时直接说短口令，例如“向左看”“挥挥左爪”“尾巴上翘”。离线由已有 ESP-SR MultiNet 识别，不需要服务端；不同产品仅装载自己支持的词表。Wi-Fi 已连接但未进入云对话时，仍可执行本地口令。

双击进入小智对话后，可自然地说“把尾巴翘起来”“头向左边看看”。云端根据设备 MCP 能力调用对应动作。云端 STT 文本仅识别意图、让出动作优先级，不抢先执行同一个关节动作；会话中的本地识别也不重复执行普通动作。停止／安静／休息仍优先处理。

主唤醒词仍走原有唤醒与对话流程。离线关键词识别是有限口令识别，不能把任意长句当作本地自然语言理解；完整中文别名、拼音和本地 token 见[词表 JSON](wzh_joint_voice_vocabulary_2026-10-21.json)。

| 产品 | 关节动作类别 | 离线识别短语数（含通用陪伴／停止等） | MCP 前缀 |
| --- | ---: | ---: | --- |
| 大熊猫 | 22 | 76 | `self.panda` |
| 小熊猫 | 24 | 81 | `self.panda` |
| 恐龙 | 33 | 100 | `self.dinosaur` |

每次明确关节指令执行一段有限动作，到位、短停留或分段摇摆，再柔和归中。方向以宠物自身左右为准，不随随机镜像改变。执行期间暂停语音随动和微动叠加，防止“只转头”时爪子／尾巴也被说话动作带走。动作仍由唯一动作任务执行，不在网络／音频回调里等待。

## 大小熊猫的头

正前为舵机 90°，头部输出工作范围统一为 **30°～150°，即左右各不超过 60°**。普通目标先经过连续软压缩：±42°内保留，较大的目标逐渐趋近 ±60°，避免多种动作都撞在同一边缘姿势。最外侧原始目标 8°／172°约映射为 31.95°／148.05°。

此范围覆盖普通动作库、用户手调配套、随机音画、爬行回看、对话随动和最终 PWM 输出。其他关节继续保留现有大幅行程。熊猫只有头部左右转轴，不能用摇头冒充点头；恐龙的抬头／低头／点头由真实颈俯仰轴完成。

## MCP 接口与提示词补充

原有 `.body` 接口继续使用 `action`，兼容旧英文名称；新增完整中文别名。`.body_capabilities` 可查询当前产品实际支持的动作，不执行动作。普通调用仍返回 bool，`details:true` 保留原来的状态详情格式；接受表示已受理，不能把它宣称为已经完成。

小熊猫上翘示例：

```json
{"name":"self.panda.body","arguments":{"action":"tail_up","details":true}}
```

大熊猫挥左爪改为 `wave_left`；恐龙点头使用 `self.dinosaur.body` 与 `nod_head`。不支持的动作或任意混杂指令参数会被拒绝，不会退化成另一个动作。动作受当前停止／休息、维护和保护状态约束，拒绝时不绕过原有控制。

可把下面一段加入三款各自角色提示词，无需替换已有性格：

> 用户明确要求某个部位运动时，按当前设备的 body 工具说明选择动作；不确定能力可先查 body_capabilities。一次请求只调用一次，不同时调用情绪工具来重复表演。左右以宠物自身方向为准。只有工具确认受理后才简短回应，不把受理当成实物已经完成。用户要求停止、安静或休息时优先 pet_control。大小熊猫只有左右转头，没有抬头和点头轴；恐龙使用自己的颈部能力。

## 后续安装与验证边界

新增离线词表在 `scripts/build_default_assets.py` 生成的 `index.json` / 识别模型资源中。未来安装需同步更新 **app 与匹配的 assets**，只更新 app 不会让旧词表自动增加命令。已有三款配置继续选用中文 `mn7_cn`，无需新增一套语音模型权重。本轮不生成这些固件或资源包；外置 Flash 音效与识别 assets 是两套资源，现有音效无需重传。

已完成 175 项主机测试。新增测试贯通按产品筛选的词表、真实解析器、真实板级路由和真实 MCP 回调；覆盖 22／24／33 类全部动作与中文别名、会话防重复、回声门控、拒绝结果。实际插值输出验证了明确指令隔离 TTS、有限完成和归中。另有 1040 组通用音画轨迹与 832 组手调配套变化回放，大小熊猫头部逐采样限制在 30°～150°。

尚未验证实机麦克风识别率、云端模型是否正确选用工具、负载下真实角度和机械间隙；这些需要安装对应固件与 assets 后在三款机器上确认。主机轨迹检查表示源码输出符合约束，不代表舵机实测角度。
