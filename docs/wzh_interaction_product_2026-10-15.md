# WZH 互动驱动陪伴策略与唤醒词选择

2026-10-16 互动反馈更新：四触点区分回应、温和状态声音、动作中搬动识别及 SC7A20H 断连重试。互动声音按用户要求只使用已有外置 Flash 文件，撤下合成短音，详见[外置音频说明](wzh_flash_interaction_2026-10-16.md)。以[本次反馈修正说明](wzh_feedback_2026-10-16.md)为准；下文 2026-10-15 的无声温和窗口、统一单点撒娇等行为属于修正前记录。

更新：2026-10-15。适用于恐龙、爬爬熊猫、摇尾小熊猫。

## 1. 当前产品策略

默认保持安静，等待用户或传感器提供有效事件。收到事件后给出对应动作，必要时配合一声本地音效；
回应结束后释放舵机，继续等待。联网对话期间保留内容动作和真实声音包络随动。

本次已移除三款的定时随机表演、定时动物叫声、定时环境音和待机生命脉冲调度，
以及开机自动探索、开机收势和结束对话时自动探索。单纯经过时间、连上 Wi-Fi 或结束会话，
都不会开启下一轮宠物表演。开关机、配网等系统提示音仍按应用原有规则工作。

原有大幅度动作素材、平滑插值、方向和软件限位保留。变化的是触发方式，
不会为了安静等待而把每次有效互动都缩成看不清的小动作。

## 2. 交互事件表

| 输入 | 当前回应 | 频率与状态约束 |
| --- | --- | --- |
| 单点轻触 | 亲昵动作，可配合已有本地声音 | 保留触摸滤波和同类请求合并 |
| 多点触摸或连续三次轻触 | 开心、玩耍类动作 | 声音受 12 秒间隔限制，动作仍可回应 |
| 长按约 1.2 秒 | 温和动作，持续接触延长温和状态 | 不反复重启动作；停止/休息时不自动唤醒 |
| 长按后释放 | 一次轻柔观察回应 | 不追加定时表演 |
| 拿起、晃动、翻面估计 | 温和回应，避免被拿起时仍剧烈摆动 | 成功接收的姿态/人体回应之间至少 3 秒 |
| 再次稳定 | 一次无声观察回应 | 稳定不等于准确检测到落地 |
| 人体输入有效 | 一次无声好奇观察 | 上电预热 10 秒；招呼间隔至少 60 秒，持续高电平不反复招呼 |
| 离线动作口令 | 一次明确动作 | 保留全部 12 条本地短语及各项保护 |
| 在线聊天 | 倾听、内容动作和声音随动 | 本地叫声暂停，结束后回到等待 |
| 停下、别动、晚安 | 停止声音和动作，释放舵机 | 必须明确唤醒才恢复活动能力 |

“拿起、晃动、翻面”是加速度估计；“温和”是动作状态，不是触觉、力或夹持反馈。
四个触点仍按真实装配处理，未假定哪个触点必然是头、背或腹部。

### 冷却的含义

姿态与人体回应在控制器接收成功后开始计算 3 秒冷却，拒绝的请求不消耗该机会。
这项冷却不会关闭独立的落体、欠压和温度保护，也不会阻止明确停止口令。
触摸仍走自己的轻触/长按状态机，不被统一压成每 3 秒才能摸一次。

普通宠物回应声音的启动间隔至少 12 秒，仅在播放请求成功后记录预算。
冷却期间仍能做动作；持续触摸、安静状态和姿态温和窗口以无声回应为主。
该限制不用于在线 TTS、系统提示音或显式声音试听。单次声音时长仍取决于实际 Flash 文件，
本轮没有新增或剪裁短音效素材。

## 3. 市面产品参考及本次采用的方向

以下参考官方资料，查阅日期 2026-10-15；采用的是交互设计思路，不代表具备对方全部能力。

| 产品 | 官方描述中的交互方式 | 对 WZH 的启发 |
| --- | --- | --- |
| Moflin | 抚摸、抱持、说话、翻转等输入影响回应 | 同样是“触摸”，轻触与持续接触应有区别；拿起时采用温和回应。来源：[CASIO 使用说明](https://www.casio.com/us/support/moflin/faq/category.moflin@life@life/) |
| Eilik | 触摸产生情绪表现，也对振动有不同反应 | 给触摸、姿态分别定义回应，避免所有输入都播放同一段开心动作。来源：[EnergizeLab](https://www.energizelab.com/eilik/) |
| aibo | 头、背、下巴、脚垫等触摸区域支持互动 | 产品装配确定后，触点应形成稳定可学习的操作含义。来源：[Sony 传感器说明](https://helpguide.sony.net/aibo/ers1000/v1/en-us/contents/TP0001970078.html) |

这些产品也有各自的自主行为。本次 WZH 的“无人互动时安静等待”来自用户要求，
不是对上述产品默认静置策略的照搬。

进一步产品化建议：

1. 按实物确认四个触点的位置，再设计稳定的“摸头、摸背”等差异，不凭软件编号猜安装位置。
2. 为轻触、开心、安抚和唤醒分别准备短声音，普通回应尽量简短；长叫声保留给明确请求。
3. 用装好毛绒/外壳的样机校准触摸与加速度阈值，记录拿起、摇晃、舵机振动造成的误触发。
4. 为儿童和青少年分别配置云端角色、故事和益智内容；本地动作不承担完整内容管理。

这些建议中的新声音素材、固定触点语义和云端角色配置尚未随本轮代码新增。

## 4. 当前已启用：分产品 WakeNet 唤醒

### 4.1 唤醒词与交互流程

| 产品 | 唤醒词 | 模型 | 状态 |
| --- | --- | --- | --- |
| 恐龙 | 小龙小龙 | `wn9_xiaolongxiaolong_tts` | 已配置 |
| 爬爬熊猫 | 你好小安 | `wn9_nihaoxiaoan_tts2` | 已配置 |
| 摇尾小熊猫 | 你好星宝 | `wn9l_ni3hao3xing1bao3_tts3` | 已配置 |

先说本款唤醒词，联网并完成云端激活后，听到提示音再说问题，例如“讲个故事”。
继续聆听和语音打断沿用小智原来的对话流程。无网络时可本地识别唤醒并恢复活动，开放式聊天需要网络。
触摸、姿态和人体感应仍用于宠物互动，不直接强行开启云端聊天；“醒醒”只恢复本地活动。

三款使用 `USE_AFE_WAKE_WORD`。WakeNet 负责普通对话唤醒，MultiNet7 保留 12 条本地口令，
无需先唤醒即可说“停下”“安静”“撒娇”等。两者复用同一麦克风和 AFE 输出，没有第二个录音链路。
同一帧出现 WakeNet 唤醒时优先处理唤醒并清理部分本地识别状态；切换后再重新开启监听。
MultiNet 本地模式过滤旧资源中的普通唤醒短语，不再将“你好小智”当成云端聊天入口。

本机 SDK 包含这些预训练模型。WakeNet9/9l 的 S3 支持与机制见
[Espressif WakeNet 文档](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/wake_word_engine/README.html)，
本地命令接口见 [MultiNet 官方说明](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/speech_command_recognition/README.html)。
声学效果仍需逐产品实测，尤其是儿童发音、扬声器回声和机械噪声。

### 4.2 其他可选模型

本地 SDK 的全部选项、配置键和模型目录检查结果见
[唤醒模型清单](review/wzh_wakenet_choices_2026-10-15.csv)。
当前每款只打包一个 WakeNet 模型，避免同时响应其他产品的名字。
云端角色名或昵称不会自动改写离线唤醒模型。

### 4.3 修改及构建

对应板型 `config.json` 的构建条目新增 `default_wake_word`，例如恐龙：

```json
"default_wake_word": "wn9_xiaolongxiaolong_tts"
```

使用正常板型构建命令就会自动选择该模型，并检查 Kconfig 是否接受。
临时试其他模型可通过 `--wake-word <model>` 覆盖默认值；不要将 `CONFIG_SR_WN_*` 塞进
`sdkconfig_append`。只改服务器角色名或只更新 app 都不够，必须更新配套 app 与 assets。
`SEND_WAKE_WORD_DATA=n` 保持原有配置，唤醒后提示音再进入录音。
当前没有在对话中任意改名并即时学习新唤醒词的功能。

## 5. 验证范围

主机回归包含三款真实动作任务循环的提取执行：模拟一小时没有输入，以及一次互动后继续静置，
确认不会接续开启定时表演或叫声；同时覆盖结束会话不再提交探索、姿态回应冷却、声音预算、
失败请求不消耗预算和毫秒计数回绕。这些测试使用时间、队列和硬件替身。

本轮三款 WZH 和普通 S3/C3 共 5 个完整构建、82 项主机测试通过。已从各款固件资源解析确认
唯一专用 WakeNet 模型、MultiNet7/FST、12 条本地短语及合并镜像偏移；
产物见[WakeNet 固件](../dist/wzh-wakenet-20261015/README.md)，结果见[验证记录](review/wzh_wakenet_validation_2026-10-15.json)。
没有烧录样机，互动动作的观感、机械限位、声学误触发和新名字准确率仍需实物验证。
旧的 `dist/wzh-interaction-20261015/` 为分产品 WakeNet 切换前版本；
`dist/wzh-hardware-20261015/` 为互动驱动改动前版本。
