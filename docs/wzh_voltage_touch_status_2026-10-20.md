# 状态页：电池电压与四路触摸（2026-10-20）

当前播放时序和回中已进一步修正，最新行为及固件见[平滑收势更新](wzh_fluid_motion_2026-10-20.md)；下方较早的末姿势等待及短收势描述为历史实现。

三款共用状态页已增加电池电压与触摸区域。电量百分比旁显示滤波后的电池电压，例如 `3.738 V`；鼠标悬停可查看毫伏值。尚无有效采样时显示 `— V`。

触摸区域显示 SW1～SW4 的当前稳定状态，支持多路同时触发；同时显示 IO5 输入电压（mV）和四位稳定编码。bit0～bit3 分别对应 SW1～SW4。例如 `0x05` 表示 SW1、SW3 同时触发。没有确认安装部位名称，因此沿用硬件通道名。

页面按现有每 2 秒刷新，显示当前状态。未稳定时显示“等待稳定”；采样失败或电压超出有效范围时显示异常，各通道显示 `—`。设备连接中断后清除旧触摸标记与电压显示，重新连上后恢复。

数据读取电源任务的已有采样缓存，网页请求不会调用 ADC。触摸消抖、传感器触发动作、电池保护和小智原生对话保持现有行为。状态接口和开发者诊断导出均包含新增字段。

`GET /api/status` 增加：

```json
{
  "battery": { "available": true, "level": 53, "voltage_mv": 3738 },
  "touch": {
    "available": true,
    "valid": true,
    "code": 5,
    "raw_code": 5,
    "voltage_mv": 950
  }
}
```

`code` 来自消抖后的稳定状态，`raw_code` 是当前电压解码，仅供诊断；过渡期间二者可能不同。未知或无效状态的 `code` 为 `-1`，不可解释为全部释放；未取得有效电压时 `voltage_mv` 为 `null`。电池 0 值表示未就绪，接口会输出 `null`。

验证：165 项主机测试通过；浏览器覆盖 16 种触摸组合、无效／未稳定／缺失数据、断线清除、390px 手机布局，以及原有配套／Flash 分别试听和开发者操作。三款 ESP-IDF 6.0.1 构建打包通过。固件身份、包哈希和界面哈希见[本轮固件清单](wzh_voltage_touch_firmware_2026-10-20.json)。
