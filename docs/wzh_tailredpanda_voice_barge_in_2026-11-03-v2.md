# 小熊猫自然打断：修复长期不触发（2026-11-03 第二版）

针对 `312f066` 的实机反馈：故事持续播放，普通人声无法打断。用户日志已经证明 MR 参考
有真实播放信号（峰值 4000～8000），但采集窗口存在大量削顶，`ref_ready` 经常为 0。
稳定期反复重置，且最大残余能量校准将门槛抬到 3140、7729，挡住普通人声。

这不是简单地取消全部回声保护。本版保留新鲜参考、输入停滞、削顶及旧 token 防护，调整
输入余量，并以实际参考音频的相关性排除自身播报。

## 收音与 AFE

- 仅参考测试模式的 ES8311 麦克风增益从 24 dB 降到 6 dB，减少 18 dB 的 ADC 前增益。
  这为用户日志中的高电平播放回声提供更多余量；实际削顶率仍需测量。
- 使用 AFE `afe_linear_gain=4` 调整输出电平，避免通过模拟增益放大已导致 ADC 削顶的回声。
- 保持 FD_HIGH_PERF，NLP 从 VERYAGGR 调为 AGGR，VAD 从 MODE_3 调为 MODE_2，减少对
  近端正常人声的压制。[ESP-SR 官方 AEC 说明](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/acoustic_echo_cancellation/README.html)
  明确说明 VERYAGGR 可能更多影响近端语音。
- 打开 codec 后读取增益寄存器；预期 `gain=6 dB reg16=0x01`，同时保持 `reg44=0x58`。
  普通构建仍为原 36 dB、单声道输入；扬声器音量及 NVS 设置不改。

## 打断判定

1. 300 ms 有参考、未削顶的有效 PCM 稳定期，随后要求累计 180 ms 的 VAD + 能量证据。
   候选中最多容许一帧被相关性否决的 60 ms 空隙，该帧不算人声；持续回声仍清除候选。
   低能量、无 VAD 或采集异常不使用此宽限。
2. 删除最大残余回声 RMS 校准。能量门槛改为 `clamp(3×静音噪声 RMS, 160, 480)`，
   不再因为一帧响亮的残余回声把门槛永久抬到数千。
3. 实际送给 AFE 的 16 kHz MR 数据中取 R，平均每 8 个样本形成 2 kHz 参考历史，
   保留 512 ms。对 post-AEC PCM 作相同平均，去均值后搜索相对延迟的归一化绝对相关性。
   分数达到 0.55 时视为播放回声，不确认自然打断；参考不足或只有直流时也不放行。
4. 固定历史 4096 字节、局部分析缓冲 480 字节；每个 60 ms 帧最多 108600 个点积项。
   优先搜索较近的参考历史，高相关匹配提前结束；不新增音频路径、解码器或每帧堆分配。
5. 参考短暂停顿和削顶会清空本次人声候选、撤销旧确认，但保留已完成的稳定期；
   输入停止更新超过 120 ms 才重新稳定并清理参考历史。
   削顶后的 240 ms 保护保留，以覆盖 AFE/VAD 处理延迟，避免刚刚削顶的延迟帧被当成人声。
6. 保留原 720 ms 有界 Opus 前缀、主任务接受确认、回复代次和新 STT 屏障，两种协议仍用 auto。

相关性检查是附加回声否决条件，不替代 AEC。真实声学路径的混响、频率响应、扬声器失真和
S3 运算时间尚未测量。没有把合成波形测试当作普通人声实机验收。

## 复测重点

- 开机核对 `gain=6 dB reg16=0x01` 和 `reg44=0x58`，防止仍在运行第一版。
- 播报时先不说话，检查完整播放及 `clipped` 是否降到 0 或很少。若仍大面积削顶，需继续
  核对实际输入增益及模拟前端，不能靠放开门槛解决。
- 在正常使用距离说“等一下，我想换个问题”。查看 `monitor`、`ref_ready`、`settle`、`vad`、
  `AEC residual`、`gate` 和 `echo_corr`；`gate` 应处于 160～480，独立人声不需要比自身播报更响。
  `echo_corr=-100%` 表示没有有效匹配分数，其他分数为最近一次候选分析结果。
- 验证首字、新问题回答、唤醒词、连续打断、双击退出、断网重连、不同音量与距离。
- 之前的 USB 掉线/整机停止仍没有复位或电源测量证据，本版未修改电源保护或宣称解决掉线。
