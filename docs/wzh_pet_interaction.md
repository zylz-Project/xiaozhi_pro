## 动作幅度

| 产品 | 调整 |
| --- | --- |
| 爬爬熊猫 | 镜像后的关键帧相对 `90/90/90` 放大 1.25 倍，再夹到各轴既有限位。头部原 132° 的目标变为约 143°，48° 变为约 38°。 |
| 摇尾小熊猫 | 相对 `90/90/150` 放大 1.25 倍，分别保留头 `8..172`、尾左右 `6..174`、尾上下 `10..178`。尾上下原 58° 的目标变为 35°；150° 默认坐姿保持。低频声音摆尾也提高可见幅度。 |
| 恐龙 | 普通完整表演的随机幅度从 `0.92..1.10` 提高到 `1.12..1.22`；生命脉冲从 `0.76..0.96` 提高到 `0.98..1.10`。明确身体指令、舵机测试和怒吼专用编舞保持原有语义。 |

放大的是相对默认姿态的偏移，不是把所有舵机角度直接乘倍数，也不扩大配置中的机械限位。两款熊猫每帧至少 420ms，按行程延长时间，平滑插值的峰值目标速度约束在 80°/s；最终输出另有限速，避免音频偏移造成瞬间跳变。恐龙保留 420ms/约80°/s平均行程限制，以及同步插值、单调 Hermite 和怒吼首帧正面仰头；输出叠加的瞬时变化另限制在约120°/s。

抱持/大角度倾斜估计、持续触摸和安抚回应期间，最终输出相对默认姿态取正常范围的35%；安静模式取60%。这是情境限制，不改变正常表演的放大关键帧。软件目标角度不代表舵机真实反馈角度，组合行程及释放后被手拨再启动仍需实机验收。

## 本地控制与持续状态

| 口令或操作 | 行为 |
| --- | --- |
| “停下”“别动” | 本地停止声音、取消当前动作并释放舵机；后续普通情绪、触摸和自主事件不能解除停止。 |
| “安静” | 结束当前对话/声音，暂停自主表演和本地叫声；主动触摸或动作指令可获得幅度较小的无声回应。再次主动发起聊天仍可对话，安静不是硬件静音。 |
| “睡觉”“晚安” | 进入持续休息，取消声音、释放舵机；不再仅播放一次 sleepy 后自行恢复。当前采用直接安静释放，不执行入睡收势编舞。 |
| “醒醒” | 恢复正常陪伴，允许重新互动，并提交一次探索回应。 |
| 本款唤醒词 | 恐龙“小龙小龙”、爬爬熊猫“你好小安”、摇尾小熊猫“你好星宝”；恢复宠物活动，网络可用并完成初始化时继续普通在线会话。 |
| GPIO0 双击 | 正常/安静时停止；停止/休息时恢复。GPIO0 单击仍保留聊天/配网功能，模拟电源键原有行为保持。 |

停止/休息状态保留到本次上电中的明确唤醒，不写入 NVS，重新上电回到正常模式。唤醒只能解除宠物暂停与动作更新超时，不能绕过欠压、过热、落体、升级或关机锁。

新增 `self.panda.pet_control` / `self.dinosaur.pet_control`，参数 `command` 为 `stop/quiet/rest/wake`。原有 MCP 动作名称及 `get_mode` 的 online/offline 返回格式保持；动作工具现在返回真实的接收/拒绝结果，不等同于报告动作已完成。

离线资源包含12条短语：原有7条，加“停下、别动、安静、晚安、醒醒”；两个停止词指向同一控制。首次使用新命令必须同时更新 app 和 assets，建议使用对应产品的合并固件。有限命令识别不提供离线自由聊天。

## 感应交互

- IO5 原有ADC阈值、中值滤波及100ms稳定判定保持；单点亲昵、多点开心，1.4秒间隔以内连续三次触摸进入开心回应。
- 保持触摸约1.2秒进入温和回应，持续保持会延长温和状态，不会反复重启动作；释放后给一次轻柔观察回应。SW1..SW4仍按真实触点编码处理，没有假定它们分别安装在头或背。
- 人体感应和姿态不再共用10秒冷却。人体输入经过启动预热后，在电池/动作允许时补一次招呼；只有控制器成功接收才消耗事件。招呼至少间隔60秒，持续高电平不会连续招呼，安静/休息/停止时不主动招呼。
- 释放舵机时的加速度变化用于估计拿起/晃动/翻面，姿态事件间隔约1.5秒。额外学习静置重力方向；持续约240ms的大角度倾斜，即使舵机通电也会请求温和状态，普通电机振动不作为这种倾斜。
- 动态事件后，稳定近1g约1.5秒并距事件至少2秒，会发一次“稳定后”回应，并延长短暂温和窗口。源码事件名 `kPutDown` 是启发式估计，不能证明已放到桌面，也不能准确区分静止抱持；实机应结合触摸和机构评估。
- 正常模式始终安静等待有效事件，不再保留前10分钟的定时自主表演；回应结束后释放舵机。

配网和激活时允许显式本地互动及人体感应回应，保持互动驱动等待；升级、启动硬件阶段、录音测试和致命错误状态禁止运动。维护禁动与会话是否在线分开，网络断开不会取消升级锁。

## 对话与动作调度

接收用户转写时先处理停止、休息和否定，再检查明确身体指令，最后做轻量文字情绪兜底。“不开心”回应温和倾听；“别摇头”停止动作，不执行摇头。“难过、担心、生气”等不再简单变成宠物睡觉或炫耀。该规则不等于完整语义或声学情绪识别，复杂引述、反讽、双重否定仍交由服务端策略与后续验证完善。

服务端 `llm.emotion` 与宠物自己的回答句子都可以提供表情动作。回答表达先等待实际扬声器PCM包络出现，再投递动作；2.5秒未能使用的表达丢弃。输出包络200ms没有更新即失效，避免声音结束后保留旧响度持续舞动。这是根据当前句子事件和真实响度进行的近似同步，没有新增逐字/音素时间戳协议。

三个控制器均使用单槽最新意图队列，优先级为明确指令 > 对话表达 > 感应；普通自主行为不覆盖用户动作。短时间重复情绪合并，待执行请求超过2.5秒丢弃。恐龙在长编舞内部每20ms检查新的意图和触摸；停止、维护和保护不必排队等待整段编舞完成。与本轮说话绑定的动作在语音结束/中断后取消；当前机械姿态平滑衔接到后续动作，仍受行程和速度限制。

停止当前对话同时取消采音发送和已排队播放，在主任务关闭语音通道；延迟到达的旧TTS不应重新启动。该处理位于传输公共应用层，WebSocket/MQTT消息格式保持。实际播音打断、单麦克风回声环境和两种服务器路径仍需联调。

## 本地启动与保护

有有效资源且没有待执行资源下载时，WZH在启动网络之前加载本地模型；首次未配网、配网中、云端版本检查等待时均可识别有限本地命令。已经开始工作的模型不会在普通激活检查时重复释放、重载。若NVS已有待执行资源下载，保留原来的“更新后加载模型”路径；缺失/损坏的资源和该更新场景不能承诺离线识别，触摸等硬件互动仍独立存在。

原有欠压3300mV禁动/3400mV恢复/3000mV关机、芯片85°C禁动/65°C恢复、自由落体释放和60秒连续通电/5秒冷却保留。新增独立的500ms运动更新超时，由电源任务约20ms轮询，超时锁定释放舵机，显式唤醒后才允许重试。它检测输出任务停止更新，不是电流/位置反馈式堵转检测。

保护位新增：64=宠物停止/休息，128=维护禁动，256=运动更新超时。原1/2/4/8/16/32含义保持。
