# WZH 三款产品的感应与保护

适用于大熊猫小安、小熊猫星宝、恐龙小龙。主板位号、连接器和供电见[硬件复核](hardware_review.md)，用户可用的命令和交互见[语音口令](../audio/voice_commands.md)与[家庭快速上手](../product/family_quickstart.md)。

## 感应

| 能力 | 实现与行为 |
| --- | --- |
| 人体 | IO41，高电平有人。连续 10 个 20 ms 样本确认变化。开机后的前 10 秒不执行招呼。先确认离开至少 3 秒，再响应新靠近。两次成功招呼至少间隔 60 秒。 |
| 触摸 | TTP224 的四路经 R-2R 接 IO5/ADC1_CH4，3 次转换取中值，连续 5 个采样确认触点。连续松开 400 ms 才重新进入可触发状态。采样中断超过 120 ms 会取消既有接触，保护和对话切换期间的旧触点不提交为新互动。 |
| 加速度 | SC7A20H 使用独立 I2C1，SDA=IO43、SCL=IO44，检查 0x18/0x19、器件 ID 和配置。±4 g、12 位、100 Hz。读取失效会暂停姿态识别并按间隔重试。 |
| 姿态 | 加速度估算拿起、摇晃、翻面和放稳。舵机通电及释放后的约 600 ms 内抑制可能由机构震动产生的姿态互动。轻摇按同轴换向判定，放稳需要新的移动和随后静止。 |
| 落体 | 连续 3 个有效样本低于 250 mg 时锁定舵机输出。之后连续 25 个有效样本回到 700～1300 mg 才解除落体锁。传感中断时继续保持已触发的保护。 |

开发者页面显示触点掩码、ADC 读数、最新三轴加速度和有效标志。模长在 700～1300 mg 时报告根据重力估算的 Pitch/Roll 和六面方向。坐标以芯片为准，按实际装配记录机身方向。MCP 的 `self.panda.get_sensors` 和 `self.dinosaur.get_sensors` 复用采样结果。 [ADC 触摸](../../../main/boards/common/wzh/wzh_touch_input.h) · [传感任务](../../../main/boards/common/wzh/wzh_sensors.cc) · [姿态判定](../../../main/boards/common/wzh/wzh_posture_input.h)

## 电池、温度与舵机

- **开机放行。** IO3/ADC1_CH2 读取 2:1 分压。分压电容需要稳定时间。启用校准的快速路径要求连续五轮满足保守阈值；未满足时等待约 15 秒并完成常规有效样本确认。开机提示音可以先播放。 [启动电池路径](startup_battery_fast_path_2026-11-09.md)
- **常规欠压。** 三款 `BATTERY_DEMO_MODE=0`。三轮时间中值连续三次 ≤3300 mV 时禁动，待静置并连续三次 ≥3400 mV 后恢复。连续三次 ≤3000 mV 时立即切断舵机和整机锁存。ADC 无效会打断连续计数，并重新锁住未确认的动作路径。低电显示和慢速电量估算有独立的滤波。 [电池保护](../../../main/boards/common/wzh/wzh_protection.h) · [电池显示](../../../main/boards/common/wzh/wzh_battery_voltage.h)
- **电量显示。** 优先使用最近 30 秒内的静置估算。持续负载的实时中值只用于缓慢下调，到静置时再确认回升。开发者页分别报告实时、保护和静置读数，外置 Flash 擦除使用实时电压检查。
- **过热。** ESP32-S3 芯片温度 ≥90 °C 禁止舵机，≤85 °C 解除该限制。主板没有 MCU 可读的舵机电流、舵机位置、充电状态或电池温度反馈。
- **舵机输出。** `ServoOutput` 集中管理 PWM 与 IO4 电源。故障立即断电，连续通电最多 60 秒、冷却至少 5 秒。电源任务独立监控 500 ms 动作更新超时，避免运动任务停更时一直供电。静置归中完成后释放。 [输出保护](../../../main/boards/common/wzh/wzh_servo_output.cc)
- **关机。** 正常长按先停止互动，保护允许时有限归中，再释放舵机并播放告别语音。提示音入队与排空合计最多等待 8 秒，期间继续采样。临界欠压立即断电。 [本地播报](../audio/system_prompts.md)

状态接口中的 `motion_faults` 位值如下。

| 位值 | 含义 |
| ---: | --- |
| 1 | 低电量 |
| 2 | 芯片过热 |
| 4 | 落体 |
| 8 | 关机 |
| 16 | 连续通电后的冷却 |
| 32 | 等待电池采样确认 |
| 64 | 停止或休息 |
| 128 | 维护禁动 |
| 256 | 动作更新超时 |

## 实机验收

逐台测试 IO41、四触点全部组合、加速度方向和震动误判，测量动作与播放同时发生时的供电跌落。核对欠压恢复、关机、温度、更新超时及重新通电时的机构行为。主机测试覆盖滤波、阈值、滞回、故障时序及计算回绕。 [整机验收](../product/product_acceptance.md) · [电池保护早期调研](wzh_battery_shutdown_research_2026-11-06.md)
