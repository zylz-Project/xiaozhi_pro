# 三款动作变化与关机完整播报候选（2026-11-06）

本轮继续保留上一轮五次连续插值、50 Hz / 14 位 PWM、实际输出限速和保护。
工作覆盖小熊猫、爬爬熊猫、恐龙。属于软件验证后的候选版，实际观感、声音、机械间隙、
供电和关机播报仍需上机确认。

## 减少重复感

- 为普通表演加入四种固定的空间侧重，改变头、爪/颈尾的中间姿态关系。每次表演只选一次，
  前后关键帧及其时长预读使用同一个种子，避免在每个 20 ms 周期随机改目标。
- 姿态映射单调，静止点、方向和准确端点保留；没有扩大既有机械角度边界。明确身体口令、
  爬爬熊猫牵引步态及恐龙专用吼叫不套用这层姿态变化。
- 四种节奏改变轻重拍的分配；四个等长原始拍的总预算相同，之后仍经过原速度/短帧预算。
  时长变化不作为提高峰值速度的手段，归中仍有独立的舒缓时长。
- 播报随动保留原有 16 种空间短语，改变四拍时长分配，继续由实际 PCM 音量、重音和停顿
  驱动；没有让没有说话的时段继续随机表演。
- 声音配套保留每文件 32 种变化的完整轮换。跨文件选择尽量避开刚用过的变化；小熊猫按
  四个变体一组的尾巴轨迹族避让。只交换尚未使用的候选，不丢弃重抽、不扩大队列。
  若这一轮只剩同类，先完成覆盖，不承诺任意输入顺序下绝无相似动作。
- 修正爬爬熊猫普通剪辑重复应用一次随机幅度增益的问题，减少不同姿态一起挤到限位。

动作 ID、原始录音、用户手调配套表、左右方向、头部范围、800/1200 ms 明确爬行时钟、
12 秒脚步配套、休息/安静模式和立即释放保护保留。

## 自审与验证口径

新回归执行生产关键帧/输出方法，覆盖三款四个非零风格种子，检查全程边界、速度、完成
预算与变化性；明确关节命令保持原意。另检查姿态映射单调性、四拍预算、分句进度端点、
交错播放的逐文件全覆盖，以及短/长吼声候选兼容。

自审发现：跨文件避让不能破坏同一文件跨轮不连重复的既有规则。现在重新排序候选时同时
保留该约束；不能找到合适候选时放弃本次跨文件避让，不损失原有覆盖。

另为恐龙的 `kKeep` 保持语义补上生产方法回归：继承的姿态已经带有本次空间变化，后续
保持帧不能再应用一次，否则静止关节会逐拍漂移。现在只处理明确给出新角度的轴。

`scripts/motion/review_fluid_motion.py --style-seed 1` 可指定确定性风格种子；交付对照覆盖
种子 1～4。轨迹是主机硬件替身产生的 PWM 量化前命令，不能作为实际舵机运动的测量。
最终测试、构建和轨迹结果见交付包 `review/validation.json`。

最终软件检查：完整主机测试 **287 项通过**（111.592 秒）；动作/关机/变体/保护相关
ASan、UBSan 检查 **25 项通过**。四个 ESP32-S3 入口（两种小熊猫、爬爬熊猫、恐龙）均用
本机可用的 ESP-IDF **6.0.1** 构建，并核对唯一板工厂、模型、镜像校验、容量和源码指纹。
项目首选的 6.0.2 未在本机使用，不能把 6.0.1 构建记成 6.0.2 验证。

轨迹对照为每种种子 1984 组，共 7936 组；音频路径在各个种子下重复对照，不能当成新增了
7936 个独立动作或录音。原有逐文件 32 种声音变化的覆盖由回归另行检查。交互预览检查了
三款选择、四种标签、播放/拖动/时间对齐，没有脚本错误。以上都不代替实机验收。

## 关机与电池

修复普通长按关机语音被旧停止事件或本地口令取消、并被误认为播完的路径；三个产品均使用
请求/generation 绑定的有界等待，保留临界欠压优先切电。关机归中期间补上电池检查。
具体依据、与 Petoi/aibo 的比较和硬件待测项见
[电池保护与关机调研](../hardware/wzh_battery_shutdown_research_2026-11-06.md)。本轮不调整电池保护阈值。

现有工作区的提示语/音频工作保留。本轮另改动其中的关机工作任务、三款关机路径及回归；
交付记录本轮相对于工作区初始快照的补丁，不把整个工作区假称为干净 Git 提交。
