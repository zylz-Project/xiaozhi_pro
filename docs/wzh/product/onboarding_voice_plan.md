# 三款产品首次使用播报

更新：2026-11-07。状态：文案设计，尚未接入固件或生成音频。

音色复刻的对话和管理页面入口现已接入，见 [当前使用方式](../audio/voice_cloning.md)。当前沿用参考版“创建后自动应用、可切回上一个声音”的流程；下表中的“先试听、确认后应用”仍是拟优化体验，首次教程调度也尚未接入。

开头概括功能，后面只带用户体验：触摸 → 轻晃 → 两句离线口令 → 邀请联网。每步说完再等用户；成功时用动作或短音效回应。核心口播约45～60秒，等待另计，以最终音频为准。

录音使用 [CSV 总表](onboarding_voice_plan.csv)，一行一个文件，只合成“播报正文”。全表65条，含61条固定录音和4条新音色动态合成；相同文案可按音色组复用。触发、重复与等待规则见CSV，以下按使用顺序阅读。

## 播放与接入约定

- 首次或主动重听时播放；记住跳过与中断进度。等待约8秒后最多提醒一次，再无操作就跳过，任意有效触摸都可完成触摸体验。
- 教程期间暂停普通自主表演和插话；用户操作、保护和关机优先。离开教程时清掉排队播报。
- 示范唤醒词、离线口令时防止自身触发；播完短提示音才接收用户输入。等待、动作和超时由程序控制，不录成音频静音。
- 首次教程中的单击跳过、双击配网需要新增路由；当前日常双击仍是进入／退出对话。无已保存网络时已有自动开热点，双击可切入讲解，无需重启热点。重听入口也需新增，当前没有“重新介绍”等离线口令。
- 大熊猫顺逆摸需接入前后触点顺序识别后启用。动作感应使用加速度计，提示轻晃即可；人体感应不承诺识别每次到来、离开或身份。
- 配网页是 http://192.168.4.1，管理页面是另一入口。按实际手机连接／页面请求推进，不用倒计时假装操作完成。需要绑定时再播验证码，数字来自当次真实结果。
- 复刻录音材料、时长按最终服务要求提供。若只替换聊天声音，页面明确标注“聊天音色”；开机、配网、关机等固定提示一起变声需增加本地音包更新与恢复机制。
- 首次音包和离线模型出厂预装；低电或硬件未就绪时先暂停动作体验。日常进入与退出对话用不同短音效，不反复播放教学。
- 两款熊猫用 panda 音色组，恐龙用 dinosaur。保留无损母带，按项目24kHz单声道流程转换；不单独拉满响度。英文热点名、IP与验证码拼接重点试听。

已核对三款唤醒词、热点前缀、离线示例及CSV与本表的一致性。音频生成后还需实机确认时长、响度与衔接。本轮不改动现有固定系统音包，制作规范见 [本地播报制作](../audio/system_prompts.md)。
