# 三款伙伴快速上手

大熊猫叫小安，小熊猫叫星宝，恐龙叫小龙。本页介绍当前固件操作；自动新手教程见 [播报设计稿 v2](onboarding_voice_plan_v2_2026-11-08.md)。三款设备和用户网页均支持音色复刻；录音与云端效果仍需实机验收。

## 不联网也能玩

轻轻触摸，或托住身体轻晃，设备会在传感、动作和本地声音资源就绪时回应。刚开机可能先等待电量与硬件检查；不要拉扯头、尾巴或关节。

| 产品 | 触摸位置（按产品装配） | 可试的离线口令 |
| --- | --- | --- |
| 大熊猫·小安 | 头、肚子、背部前后两个位置 | “陪我玩”“抱抱我” |
| 小熊猫·星宝 | 头、背部、肚子、尾巴 | “来玩吧”“摇摇头” |
| 恐龙·小龙 | 头、胸前、背部前后两个位置 | “陪我玩”“给你吃好吃的” |

大熊猫可以说“挥挥左爪”，小熊猫可以说“摇摇尾巴”，恐龙可以说“抬头”。完整说法和打断词见[三款产品语音口令](../audio/voice_commands.md)。触点与板级通道的对应以装配为准；大熊猫顺逆摸按 v2 计划接入。人体感应可留意附近动静，不保证每次走近或离开都回应，也不识别身份。

想暂停动作说“停”，想休息说“晚安”，想恢复活动说“醒醒”。本地模型就绪后即可使用这些口令。

每次轻触只回应一次，松开后可以再次触发。恐龙背部靠近脖子到靠近尾巴的顺摸会触发较温和的回应，反向逆摸会触发较活泼的回应。对话中摸三款设备时，聊天服务可以收到触摸部位，恐龙还会报告顺摸或逆摸。

## 连接网络与聊天

没有保存过Wi-Fi时，设备会自动开启配网热点：

| 产品 | 手机连接的热点前缀 | 聊天唤醒词 |
| --- | --- | --- |
| 大熊猫 | `CrawlPanda-` | 你好小安 |
| 小熊猫 | `RedPanda-` | 你好星宝 |
| 恐龙 | `Dino-` | 小龙小龙 |

1. 手机连接对应热点；提示不能上网时选择保持连接。
2. 打开配网页；没有自动弹出时，在浏览器地址栏输入 `http://192.168.4.1`。
3. 选择家里的2.4GHz无线网络，输入密码并连接。
4. 对话服务已在出厂时配置，联网后第一次双击电源键会播放新手教程。
5. 听到聆听提示再说话。下次可以双击，或说本款唤醒词开始对话。

设备回答时，叫一声本款的“小华”“小武”或“小威”，也可以说“停”“等”“说”“喂”或“你好”。等回复停下后接着说。

配网页用于连接Wi-Fi。联网后，手机重新连接设备热点，打开 `http://192.168.4.1` 进入设备详情页（页面密码写在说明书里）：可看电量、调音量、看说明书和设置专属音色。开发者管理台在设备局域网 IP 的 8080 端口，仅开发者使用。网络连上但聊天暂不可用时，先使用触摸和离线口令，不必反复清除网络设置。

手机连着设备热点时，可从配网页、登录页和详情页打开电子说明书。也可直接访问 `http://192.168.4.1/manual`，配网前即可查看。阅读时目录停留在顶部，手机上可横向滑动目录并点选章节。

设备曾完成配网后，即使家里路由器暂时断开，手机连着设备热点仍可登录看详情、调音量或查说明书。需要换网络时，从详情中主动进入网络设置。

两台手机可同时连接同一个设备热点并分别登录。配网、音色创建和恢复出厂是设备共用任务，正在进行时页面会提示忙。

## 按键与声音

- 日常快速按两下电源键可进入或退出对话。两次短按之间先松开按键，双击窗口约 0.65 秒。进入和退出有不同提示音。
- 长按电源键：正常关机。不要把双击变成长按。
- “首次教程中单击跳过、双击进入配网讲解”是 v2 播报设计的方向；当前固件还没有教程路由，未实现前不要按此操作。
- 离线及配网引导播完后，等待第一次双击期间仍可用触摸和离线口令互动，设备会按正常节奏做本地动作、播放音效。联网后第一次双击会播报联网教程，播完自动进入对话，播报期间可再次双击取消。恐龙通过 Wi-Fi 或 4G 联网时都适用。
- 聊天中短暂断网会先结束本轮播报和收音。20 秒内网络和对话服务恢复后，设备会重新提示开始聆听。恐龙主动切换 Wi-Fi 和 4G 时等待 45 秒。等待期间可以双击，或在详情页点“取消连接”。

安静、休息和退出对话不代表物理断开麦克风。本地玩耍不需要联网；联网聊天的语音处理以实际服务与使用说明为准。

设置语音服务后，可以两种方式创建专属声音：在设备页面用手机录音或选择手机里已有的录音上传；也可以在聊天中说“复刻音色”，或让设备进入录音提示后用产品麦克风录音（开发者页也可“用设备麦克风录音”）。说“切换音色”可以选择已有声音。三款产品的用户页面都支持手机录音并上传音频文件；支持系统录音的手机可以从页面调用录音器，iPhone 可先用“语音备忘录”录音并存储到“文件”，再选择上传。操作时请保持手机连接设备热点，如果手机切换了网络，重新连接后返回页面查看结果。成功创建后自动应用，可试听和切回上一个声音。步骤与取消方式见 [音色复刻](../audio/voice_cloning.md)。
