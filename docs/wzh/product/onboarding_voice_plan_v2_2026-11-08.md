# 三款产品首次使用语音教程（优化稿）

> 本文用于确定**建议播报文案和触发时机**，并不表示自动新手教程已经实现。请以本文件及同步的 [录音清单](onboarding_voice_plan_v2_2026-11-08.csv) 制作音频；已有功能与待开发项目见文末。三款共用的文案分别用熊猫、恐龙音色录制。

## 一、体验原则

- **先认识，再体验**：开场简单介绍触摸、动作、离线口令、联网聊天和专属声音；随后每次只引导一个动作。
- **不催促**：每一步播完后等待用户操作；没操作就温和地进入下一步，不反复提醒。联网是可选项，本地互动不受影响。
- **声音和动作有先后**：开机提示音和已启动的特色动作结束后再开始教程（动作无需等待配网提示，动作被保护或互动取消时不等待动作）；播报关键口令和唤醒词时防止设备识别自己的声音，播完提示音再听用户说话。
- **操作优先**：用户触摸、说话、关机或有低电保护时不与长播报抢占；教程可跳过、暂停和重听。优先保证安全，不能因教程屏蔽停止或休息指令。
- **按真实状态播报**：Wi-Fi 已连接不等于聊天可用；未绑定、网络异常、服务不可用分别提示，不提前宣布成功。开机电量检测有快速路径与回退路径，时长随状态变化，不承诺固定秒数。
- **预计时长**：介绍和示范约 60～90 秒，包含等待操作可能更长；配网、绑定和首次聊天另计，以实际进度为准。

**音色复刻的使用说明**：聊天中说“复刻音色”“我想复刻音色”或“帮我复刻音色”，按设备提示对着产品录音；设备页面也可选择用设备录音或上传手机里的录音。当前用户页提供设备录音和选择已有音频文件上传，没有网页直接手机录音入口。iPhone 可先用系统录音并保存到“文件”，再选择上传。联网、语音服务及对应权限需要就绪；不要在语音里承诺所有手机都能直接网页录音。录音前应得到声音提供者同意。详见[音色复刻](../audio/voice_cloning.md)。

## 五、流程和分支设计

| 顺序 | 时刻和处理 |
| --- | --- |
| 1 | 首次开机，开机提示音和已开始的特色动作结束、音频可用后播放开场；如果动作被取消或跳过，不等待动作。动作受电池保护限制时不强行动作；教程等待或按安全状态调整，避免反复播报。 |
| 2 | 播触摸引导，等待约 8 秒；有触摸则回应，没有则自然继续。小安增加顺摸和逆摸示范，各等待约 6 秒。 |
| 3 | 播轻晃引导，等待约 6 秒；然后依次播两条离线口令，每条提示音后等待约 6 秒，识别成功则回应，超时继续。 |
| 4 | 依次播人体感应和联网邀请。邀请后接热点引导；等待手机连接约 60 秒，超时则播不联网收尾，结束教程并保持本地互动。 |
| 5 | 首次没有已保存 Wi-Fi 时设备会自动开启热点，已有 `wificonfig` 提示；按实际热点状态播对应引导。手机连接、页面打开、提交和连接结果均按真实事件推进，不以固定等待代替。 |
| 6 | 若手机提示无网络，引导保持连接；页面未弹出时播地址。已打开页面则跳过浏览器提示；联网失败允许重试。仅当可以将断开事件归属于正在配网的手机时，提示重新连接，避免误报。 |
| 7 | 设备取得 IP 后播已联网；有激活要求才播验证码；服务真正就绪后播 `success` 和对应唤醒引导。已联网设备跳过配网步骤，服务未就绪则走相应分支。 |
| 8 | 用户首次退出聊天后，可在空闲时播放专属声音提示一次；已有音色创建任务或用户正在互动时跳过或延后。 |

**按键与中断设计**：建议教程中短按跳过，双击遵循当前设备状态：服务就绪时进入或退出对话；未联网时不能承诺双击一定进入配网。长按关机以及“停下”“晚安”等安全和休息指令优先。跳过、恢复、重听的触发方式和按键路由属于待实现设计，不能在功能完成前写入正式说明书作为现有操作。

## 六、录音和制作

- **清单**：[onboarding_voice_plan_v2_2026-11-08.csv](onboarding_voice_plan_v2_2026-11-08.csv) 与本文播报正文保持一致；专属 `cp_*`、`rp_*`、`dn_*` 各录一份，共用 `common_*` 按熊猫和恐龙两个音色组各录一份。两款熊猫可共用熊猫音色。
- **复用**：`wificonfig`、`activation`、`success`、`low_battery`、`power_off` 和动态数字 0～9 使用已有系统提示，不重录；具体以[系统播报说明](../audio/system_prompts.md)为准。
- **音频**：参考现有系统音包的 24 kHz 单声道 Opus、目标 RMS -19.5 dBFS、峰值不超过 -1.5 dBFS；保留母带与来源信息。先检查实际播放响度和清晰度，再统一生成音包。
- **朗读**：语速自然，句间留短停顿；操作等待时间及提示音由固件控制，不录进人声。英文热点前缀、IP 地址和“二点四 G”需单独试听；不念页面密码。
- **优先级**：主线、热点及 Wi-Fi 引导、联网结果和唤醒引导为首批；失败、断线、跳过、重听、隐私、音量/充电帮助、专属声音发现及可选语音退出为条件提示。建议文件按音色组和音频 ID 命名，文案变更同步更新清单和音包元数据。

## 七、实现与验收前提

1. 首次教程状态机、进度持久化、跳过/恢复/重听入口，以及配网、页面和服务就绪事件驱动，均需实现并验证；OTA 不应意外重复首次教程。
2. “再见/拜拜”退出对话作为可选教程单句：当前固件未发现直接按这些词退出的本地规则，可能依赖云端服务的识别与结束会话行为；三款需实机逐一验证，未验证通过前不播放、不对外承诺。默认聊天引导只介绍双击退出。
3. “挥挥左爪”“摇摇尾巴”“抬头”已分别列入三款当前源码的离线词表与动作映射；仍需确认设备所刷固件和 assets 匹配、模型接受这些词，并逐款实机验收识别率和动作。小安背部顺逆摸需先完成顺序识别并保留单点触摸。
4. 触摸位置须核对实际装配和触点映射；人体感应仅对符合条件的靠近可能有回应，尚无明确的“离开”事件识别，不承诺识别身份或每次靠近都有动作。热点名称、是否免密、标签尾号及页面密码来源以量产配置为准；文案不预设标签一定存在。
5. 用户页设备录音、手机文件上传、聊天触发音色复刻及云端服务权限需实机验收；网页直接手机录音不是当前用户页功能。手机热点断开、打开网页、联网与服务就绪等事件须能准确获取，不能按倒计时假定成功。
6. 与已有开机提示、配网提示、唤醒/退出提示音去重；离线口令、唤醒防自触发，同时保证“停下”“晚安”和关机可用。
7. 三款逐一验证首次开机、低电、触摸、轻晃、离线词、人体感应、跳过及重听、热点连接、手动打开页面、配网失败重试、激活、聊天和音色复刻；覆盖 iPhone 与 Android。实机试听音量和录音质量，核验各手机录音入口的实际行为。
