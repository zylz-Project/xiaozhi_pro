# 三款产品整机实测验收

按产品和样机分别填写。记录板号、机构版本、固件构建名与 SHA256、内部和外置 Flash 型号、电池批次与实测电压、测试日期和日志。每项记录通过、失败或不适用。

| 场景 | 样机上要验证的行为 | 结果 |
| --- | --- | --- |
| 冷启动与换电 | 满电、接近低电阈值及换电后分别启动。确认过渡采样不会给舵机提前上电，并记录快速确认及常规确认时长。 | 待测 |
| 电源键与关机 | 开机保持按下再稳定松开。验证双击、长按反馈与松手取消、关机提示和电源锁存。保护已触发时观察舵机是否保持断电。 | 待测 |
| 各轴与负载 | 核对默认位、舵机型号、方向和组合行程，观测极限姿态下的碰撞、线束拉扯、电压跌落、电流和温升。小恐龙重点检查 270° 机构和 IO8 尾部限位。 | 待测 |
| 离线交互与触点 | 无 Wi-Fi 启动，逐个验证物理触点、按住后释放、轻晃与翻转、自身动作不误触发。验证小恐龙顺逆摸、摇尾小熊猫 SW4 隔离配置、三款离线口令、单说“拜拜”和“关机”播完提示再断电，以及“摆摆尾巴”、否定语句和扬声器回声不触发误关机。 | 待测 |
| 首次教程与待机 | 首次开机走完离线、配网及首次对话引导。中途取消、关机，再开机检查进度。验证空闲提醒、休息与自动关机。 | 待测 |
| Wi-Fi 与手机网页 | Android 和 iPhone 先测试热点、首次配网、错误密码回退与换网，再验证热点换信道导致响应中断时的恢复。验证路由器长时间离线后重连。 | 待测 |
| 对话、唤醒与打断 | 分别检查 WebSocket 和 MQTT/UDP 服务配置。重复唤醒、播放、再提问和打断，验证弱音、外音与回声；在连线、聆听和播报时分别断网。记录唤醒到能说话、说完到首字出声、断网恢复到能继续对话的实测耗时。 | 待测 |
| 小恐龙 4G | 验证无模组、无 SIM、弱网与恢复。双向切换 4G 和 Wi-Fi，分别检查网页状态、会话恢复和云端音色。 | 待测 |
| 音色 | 分别从设备麦克风及手机文件创建，检查取消、试听、切回、重命名、删除和云端失败提示。 | 待测 |
| 恢复出厂 | 验证网页双方提示、失败后保留凭据、成功清除专属音色及教程和 Wi-Fi。核实离线或云端中断时可重试。 | 待测 |
| 内部 OTA | 启用适用的更新路径，验证不同包体、断网及回滚；确认固件身份、分区表与空间余量。 | 待测 |
| 外置 Flash | 使用实际 NOR 或 NAND 检查旧音频可读、Audio Hub 更新、容量满、校验失败以及 TOC 改写期间断电。 | 待测 |
| 持续运行 | 记录空闲、反复会话、网络频繁重连和连续动作后的堆内存、负载、功耗及温升。 | 待测 |

温度日志来自板上的芯片测温，舵机与电池的温升要单独测量。当前软件构建与测试记录见[构建与兼容性](../../wzh_migration.md)，该记录所对应的样机验收尚待执行。

对话延迟用同一组问题分别测默认音色和复刻音色，包含短答、短开头加下文、多句长答和连续追问。小恐龙分别测 Wi-Fi、正常 4G 和弱 4G。录下用户末字和设备首字，汇总开播耗时的中位数和 P95，同时检查首尾字、句中停顿和打断后首句。稳定网络下回复应连续完整。弱网下对比改动前后最长的非语义停顿和每轮可听卡顿次数，确认提速没有增加卡顿。

小恐龙可连接设备热点，登录 `192.168.4.1:8080`，在同一轮测试前后导出诊断。对比 `rebuffer_count` 和 `queue_full_count` 的增量，并与录音对应。验收以实际听到的停顿、漏字和断续为准。
