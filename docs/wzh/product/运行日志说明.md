# WZH 产品运行日志说明

适用于大熊猫、小熊猫和恐龙。时间戳由 ESP-IDF 输出，通常是设备启动后的毫秒数。

## 常用日志

- `Battery ...`：`live` 是按电路分压比换算后的实时电池电压，`rest` 是最近静置电压；`rest_age=-1` 表示尚未得到静置值。`source` 为 `live_estimate` 或 `pending`，表示百分比使用最新有效电压估算或尚不可用；`protection`、`ready`、`low` 是舵机电压保护状态。`valid=0` 表示采样失败或换算电压不在有效范围，不代表电池电压为零。
- `Battery protection low=...` 与 `Battery reminder low=...`：分别记录低电动作保护和电量提醒的状态变化，以及当时的电压。首次 15 秒内不根据可能尚未稳定的采样播报低电语音；正常低压保护及严重欠压关机仍持续工作。
- `Battery startup sample accepted` / `Power-on sound requested as soon as audio is ready`：开机电池采样和音效播放请求；两者独立进行。早期 ADC 数值可能受分压电路电容残留影响，不能替代实测电池电压。
- `Startup gesture started`：启动动作已投递；`Startup gesture skipped` 会输出经过时间、保护阻止、设备模式及对话或关机状态。启动动作受保护和主动交互约束。
- `Onboarding: step=... narration=start`：教程准备播放某句；`feedback=interaction` 表示识别到用户互动，`feedback=demo` 表示等待后自动演示。`feedback unavailable` 表示在有限重试期间未能提交反馈，需要结合舵机保护、Flash 和音频状态排查。
- `Voice request: ... text=...`：教程或系统语音已发起播放请求，文本对应当前产品录音；是否完整播出仍需结合完成或中断日志。`Voice server sentence: ...` 是服务端发来的助手播报文本，不保证音频一定成功播放。激活验证码数字不写入日志。
- `step=page waiting for hotspot client` / `hotspot client connected`：等待手机加入设备热点；设备已经联网时不必等待。`step=connected waiting for double click and conversation service` / `waiting in background`：等待首次双击及聊天通道；Wi-Fi 已连不等于聊天服务可用。
- `Interaction=... sound=... source=paired` 表示使用固件内已有的音画配对；`source=external_flash` 表示使用外部 Flash。选择成功不等于扬声器和舵机的实测效果已验证。
- `Protection=... ON`、`Critical battery voltage` 和关机失败/超时信息保留为警告或错误；严重欠压路径可能直接断电。
- `WiFi disconnected, reason: 200 (beacon timeout)`：设备一段时间没有收到路由器信标。其后的 TLS/MQTT 读错误可能是连接断开后的连锁结果；需结合信号、路由器和供电排查。Wi-Fi 不可用或设备维护时，MQTT 只周期检查条件，不新建连接；网络恢复后再尝试。
- `Keyword detected; waiting briefly for near-end voice confirmation`：已识别到打断词，正在等待短暂的人声及回声确认；确认通过才会中断。识别率和扬声器回声抑制仍需实机验证。

## 详细音频诊断

`MR capture` 和 `Opus quality` 属于 DEBUG 级，正常 INFO 日志不再周期刷屏。需要时在 ESP-IDF 的日志配置中允许编译和输出 `AudioService` 的 DEBUG 级日志；仅提高运行时级别不能启用编译时已裁剪的日志。不要长期打开高频诊断，以免增加串口输出和音频任务负担。

## 分享日志

默认不再打印 SmartConfig 和 BluFi 密码、用户语音识别文本、完整网络报文或完整服务地址。按用户要求，日志会打印助手播报文本；其中可能包含对话中的个人信息。日志也可能包含 Wi-Fi 名称、音频文件名和设备状态，分享前请自行确认。固件编译通过不能替代三款实机的电压、音频和舵机验证。
