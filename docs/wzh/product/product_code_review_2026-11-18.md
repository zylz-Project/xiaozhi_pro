# WZH 三款产品代码审查（2026-11-18）

本次检查覆盖爬爬熊猫、小熊猫、恐龙的板型配置，以及共享网页、网络选择、开发者入口和现有主机测试。工作区包含进行中的改动，本记录对应审查时的工作区，并不代表完整量产认证或所有代码路径均已逐行审查。

## 2026-11-19 运行逻辑复查

- 三款共用的关机流程会屏蔽晚到的激活、验证码和云端提示。告别音独占播放队列，正常播完或等待超时后断电，临界欠压仍直接断电。
- 本地音频的停止操作只清理对应的播放代次。配网、低电和开机保护提示会等已预留的本地音频。退出会话后，晚到的旧语音包也不能写入下一轮会话的准备队列。
- WebSocket 在链路切换时处理网络接口为空的情况，校验音频帧长度后再解析。MQTT/UDP 沿用既有回调和播放接口，三款的会话隔离都在同一应用层处理。
- 固件 OTA 支持分段到达的文件头，大小超出分区或下载提前结束时中止写入。资源更新收到有效负载后才卸载旧资源的映射，完整接收后才写入头部并清除待更新地址。
- 三款默认关闭在线固件和资源更新，设备继续获取激活与语音服务配置。启用在线更新前，要验证手动 OTA 占用主任务、慢网时的关机和升级失败恢复。资源只有一个分区，写入中断后仍要验证使用已保存地址重新联网恢复。
- 出厂热点和开发者入口的认证策略仍需要产品决策。软件验证还需要三款实机覆盖低电、断网重连与长时间运行，恐龙另需验证 4G 弱网和 270° 舵机机械行程。
- 472 项主机测试通过。ESP-IDF v6.0.1 下三款均编译通过并确认关闭在线更新。大熊猫、小熊猫、恐龙 4G 的应用分区分别剩余约 18%、16%、5%。恐龙合并镜像和发行压缩包已校验，未烧录。

## 发现及处理

1. **恐龙启动期间网页状态不一致（已修复）。** 恐龙会并行连接 Wi-Fi 和探测 4G；探测尚未决定云端通道时，Wi-Fi 可能已连接。网页原先直接依据 Wi-Fi 链路判断产品在线，可能提前开放需要联网的页面和操作。现在网页使用板级 `IsNetworkAvailable()` 判断已选通道，Wi-Fi 的原始连接状态仍用于展示。
2. **开发者入口及用户页面的访问控制不适合直接作为量产安全边界（待产品决策）。** 三款共用的开发者密码为固定值 `1`，用户页面密码可从公开的热点名称推导，热点是开放的，页面通过 HTTP 访问。限速和会话令牌不能使这些凭据变成秘密。附近人员可尝试访问设备，局域网内人员也可能访问开发者端口；无线链路上的敏感信息缺少传输保密。现有密码和访问方式属于既定产品行为，本次没有擅自改变。量产前应设计每台设备独立秘密、首次绑定和恢复流程，并评估本地安全传输及开发者功能的出厂策略。
3. **部分通用联网调用假定网络接口非空（待加固）。** 恐龙探测阶段 `GetNetwork()` 可以返回空指针；如在此期间通过其他路径触发 OTA 或资源下载，`main/ota.cc` 和 `main/assets.cc` 中存在未经检查即解引用的调用。正常启动流程等待网络连接事件，但仍需为异常调用、启动竞争和离线重试增加防御，并验证所有相关调用方和两种传输。此项尚未修复，不能据此声称已复现崩溃。
4. **恐龙 4G 自动选择和软硬件边界待实测。** 当前策略检测到模组后本次开机固定使用 4G，即使 SIM 或注册失败也不切回 Wi-Fi；无模组才回退。应验证用户能理解并处理这一状态，同时实测有/无模组、无 SIM、弱信号、断网重连及音色服务。

## 上市前验收重点

- 三款分别实测按键、触摸、姿态、音频采集和播放、唤醒、打断、离线交互、关机、低电保护、舵机方向及机械行程。
- 分别检查配网、重连、云端对话、升级和外置音频维护；断电或中断时验证数据和凭据恢复。
- 在真实电池、电源和装配条件下测试长时间运行、发热、舵机负载及供电复位。
- 检查固件分区余量、批量烧录及版本回退；构建通过不能代替实机验收。
