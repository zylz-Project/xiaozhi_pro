# 三款产品的离线口令、唤醒词和打断词

适用范围为 `4g` 分支截至 2026-11-20 的构建配置。大熊猫和小熊猫的普通版与 `-barge-in` 版使用相同词表，恐龙使用 `wzh-dinosaur-270-servo` 4G 版。离线识别在设备本机完成，待机唤醒后进入聊天需要网络和聊天服务就绪。

## 待机时怎么唤醒

| 产品 | 正式唤醒词（WakeNet） | 本地备用唤醒词（MultiNet） | 回答时可用来打断的本款称呼 |
| --- | --- | --- | --- |
| 大熊猫·小安 | 你好小安 | 小华 | 小华 |
| 小熊猫·星宝 | 你好星宝 | 小武 | 小武 |
| 恐龙·小龙 | 小龙小龙 | 小威 | 小威 |

待机时可直接说口令让设备做动作。想聊天时说本款唤醒词，听到进入对话的提示音后再提问。**“醒醒”用于恢复本地活动。**

## 回答时怎么打断

三款都可以叫一声本款的名字，或单独说 **“停”**、**“等”**、**“说”**、**“喂”**、**“你好”**。设备在本机识别打断词并确认有近端人声后，会停下当前回复并继续收音，这时可以接着说新的内容。快速双击电源键可完整退出对话。

| 三款共用 | 可以说的话 |
| --- | --- |
| 回答时的专用打断词 | 等、说、喂、你好 |
| 也可用于打断的本地停止口令 | 停、停下、别动、先别动、停止动作、不要摇尾巴、别摇头、不要动 |
| 兼容已录制的语音教程 | 等一下、我要说话 |
| 本款专属词 | 见上表最后一列 |

正式 WakeNet 唤醒词用于待机唤醒。待机时说“停”可以停止当前本地播放和动作。扬声器回声和环境噪声会影响识别。

## 对话中的关节控制和触摸

进入聊天后可以直接说“摇摇头”或“向左看”。小熊猫和恐龙还可以说“摇摇尾巴”，大熊猫可以说“挥挥左爪”。云端根据用户的语音调用下列 MCP 工具，设备执行对应动作并遵守舵机保护和活动限位。

明确的关节指令执行期间，设备保持其他关节的位置，暂停通常的跟声摆动。例如“摇尾巴”只使用尾巴，“挥左爪”只用左爪。说“身体归中”可以让各关节一起归位。

| 产品 | MCP 工具 | 参数示例 |
| --- | --- | --- |
| 大熊猫 | `self.panda.body` | `action=shake_head`、`action=wave_left` |
| 小熊猫 | `self.panda.body` | `action=shake_head`、`action=wag_tail` |
| 恐龙 | `self.dinosaur.body` | `action=shake_head`、`action=wag_tail`、`action=nod_head` |

对话中摸设备，固件会把触摸位置作为一条文字输入交给同一个聊天会话。例如摸头时发送“设备感应到用户摸了你的头。请自然回应。”固件在听用户说话和播放回答时暂缓发送，短时间内只保留最近的触摸，退出对话或断开网络后丢弃待发送事件。云端需支持 `listen/detect` 文字输入。[小智开源服务端的文字处理](https://github.com/xinnan-tech/xiaozhi-esp32-server/blob/main/main/xiaozhi-server/core/handle/textHandler/listenMessageHandler.py#L49-L105)

| 产品 | SW1 | SW2 | SW3 | SW4 |
| --- | --- | --- | --- | --- |
| 大熊猫 | 头 | 肚子 | 背部前侧 | 背部后侧 |
| 小熊猫 | 头 | 背 | 肚子 | 尾巴 |
| 恐龙 | 头 | 胸前 | 背部靠近脖子 | 背部靠近尾巴 |

两款熊猫按当前上手指南的触点顺序设置，装机时逐点核对。

恐龙的 SW3 位于背部靠近脖子的一侧，SW4 位于背部靠近尾巴的一侧。从 SW3 摸到 SW4 是顺摸，从 SW4 摸到 SW3 是逆摸。待机时，顺摸走温和的安抚动作和声音，逆摸走活泼的动作和声音。对话时，文字事件还会带上顺摸或逆摸的方向。

## 三款共用的离线口令

| 用途 | 可以说的话 |
| --- | --- |
| 邀请玩耍 | 来玩吧、陪我玩、跟我打招呼 |
| 亲近互动 | 抱抱我、过来抱抱 |
| 喂食互动 | 吃饭啦、吃一口、给你吃好吃的 |
| 进入休息 | 睡觉吧、晚安、休息一下 |
| 停止动作和当前互动 | 停、停下、别动、先别动、停止动作、不要摇尾巴、别摇头、不要动 |
| 进入安静模式 | 安静、安静一点、小声一点 |

| 摇头 | 摇摇头、摇头、晃晃头、甩甩头、摇个头 |
| 向左看 | 向左看、头向左转、看左边、向左转头、往左边看看 |
| 向右看 | 向右看、头向右转、看右边、向右转头、往右边看看 |
| 头部回正 | 头部回正、头回正、头看前面、看看我 |
| 头向左摆 | 头向左摇、向左摇头、头往左摆 |
| 头向右摆 | 头向右摇、向右摇头、头往右摆 |
| 左右巡视 | 左右巡视、左右看看、转头看看 |
| 身体归中 | 身体归中、动作归中、恢复默认姿势、回到中间 |

普通动作词适合在设备待机、扬声器安静时使用。动作还受当前模式、维护和硬件保护限制。处于停止或休息模式时，可以先说“醒醒”。
