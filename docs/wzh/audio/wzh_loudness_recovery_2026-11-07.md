# WZH 满音量响度恢复与音质保护（2026-11-07）

用户实机反馈：上一版在音量 100 时仍明显偏小，需要继续提高响度并保持音质。上一版只校正了硬件增益和最大模拟输出，尚未充分利用偏轻音源的数字余量；本轮补齐限幅前的响度处理。三款普通版与人声打断版均适用。

## 处理方式

保留图纸确定的 20dB 功放增益补偿、音量 100 对应的 DAC -23dB（含 3dB 目标余量）以及 0.84 数字峰值上限。新增 **9dB 的固定限幅前增益**，由 RMS 保护和现有前瞻限幅器约束偏响材料；实际提升取决于音源，不能把 9dB 参数直接称为实测声压提升。

```mermaid
flowchart LR
  A[PCM及原素材增益] --> B[原高通与可选EQ]
  B --> C[固定增益 +9dB]
  C --> D[RMS保护]
  D --> E[平滑峰值限幅 0.84]
  E --> F[原DAC音量与功放补偿]
  F --> G[扬声器]
```

- 三款板配置 `AUDIO_CODEC_SPEAKER_MAKEUP_DB=9.0f`，通过唯一 ES8311 构造器传给 `AudioCodec`，在扬声器保护初始化时配置。其他板默认 0，不启用该处理。
- 增益在浮点 DSP 中、RMS 和峰值检测之前应用，不先把 int16 音频放大截断。声音较轻时利用空余动态范围，过大的峰值仍受到限制。
- 对新响度配置统一采用 RMS → 平滑限幅的次序，避免大熊猫／恐龙原先独立衰减重复压低响度。三款均使用已有 1ms 延迟内的有限平均增益，控制峰值前的增益突变；保留 5ms 起音平滑。
- 固定增益不会在静音期间持续自动抬升；源文件本身的底噪仍会随音频一起放大，本轮没有新增降噪器或声称消除底噪。
- 新路径继续按采样更新，跨包保留状态；reset 清空旧声音历史并保留当前配置。没有逐帧分配、大量缓冲或新任务。24kHz 硬件时钟、原 EQ、NVS 音量、提示音、模型、麦克风增益和协议不变。

设计依据：[乐鑫 DRC 说明](https://github.com/espressif/esp-adf-libs/blob/master/esp_audio_effects/docs/README_DRC.md) 将 makeup、动态控制和增益平滑作为避免过载的配合机制；[Signalsmith 限幅器设计](https://signalsmith-audio.co.uk/writing/2022/limiter/) 说明了峰值保持与有限长度平滑对增益突变的控制。本轮复用仓库已有保护器扩展实现，没有引入该 DSP 库或额外神经处理。

## 数字音频对比

基线为任务开始时的实际 `speaker_protection.h`，与本轮头文件分别编译原生处理程序，使用相同 24kHz 单声道输入。没有对输出做事后响度归一化、没有模拟功放或扬声器。

| 样本 | 数字响度提升 |
| --- | ---: |
| 大熊猫 4 段已内置语音 | +4.7～+5.3 LU |
| 小熊猫 4 段已内置语音 | +3.3～+4.3 LU |
| 恐龙 4 段已内置语音 | +3.9～+5.7 LU |
| 8 秒自合成音乐，原 EQ 关闭／开启 | +6.7／+6.4 LU |
| 低电平 1kHz 纯音，两种原 EQ 配置 | +9.0 LU |

16 组新输出采样峰值均不超过 27,524，int16 满幅样本均为 0，长度与基线一致。关闭新配置后，这 16 组输出与旧生产实现**逐样本一致**。小信号 1kHz 的数字 THD+N，基线约 0.086%～0.097%，新输出约 0.059%～0.080%；这是数字测试，不能用作实物功放／喇叭 THD 指标。

对比 WAV、具体 LUFS／峰值、源程序和完整结果保存在 `dist/wzh-loudness-20261107/review/`。电脑试听可比较这些处理后的音频，不能代替三款机身的声音验收。音乐样本是自主合成，未取得用户实际播放的官方音乐流，不能将其作为官方原曲的复现。

## 实机仍需确认

本轮未烧录，数字结果不能证明实机音质已经保持不变。需在三款各自音量 100 对照相同对话、内置声音、提示与音乐，确认实际响度足够且无破音、泵动或明显底噪；同时检查 70／80／90 的调节、静音、连续播放、停止／重启、双击退出、人声打断和重连。平均播放功率提高后，还需检查功放供电、温升和动作同时运行时的表现。

若同一音源在新方案下仍明显不够响，应结合实际功放 VCC、输入电阻实装、扬声器负载与声压测量继续定标；当前没有这些实测值，不能直接承诺恢复旧版饱和时的声压。
