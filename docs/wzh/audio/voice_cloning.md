# 三款产品音色复刻与管理

更新：2026-11-09。已接入大熊猫、小熊猫、恐龙；软件验证和实机验收分开记录。参考 [feature/weijian-dev](https://github.com/zylz-Project/xiaozhi_pro/tree/09b07763778c91480540d44f00a68f109f6645d3)，共享实现位于 `main/boards/common/wzh/voice_tts/`。

## 怎么使用

1. 先让设备连接 Wi-Fi。手机保持连接设备热点，打开用户页 `http://192.168.4.1`，输入说明书里的页面密码，进入设备详情页。三款产品都在声音区提供音色复刻。
2. 如果页面提示“语音服务未配置”，由开发者在设备局域网 IP:8080 的“音色复刻”页保存北京地域的百炼 API Key；量产机应预置 Key。Key 保存后不回显。
3. 填写名称后，可以选两种录音方式：
   - **设备麦克风**：在聊天中说“复刻音色”或“我想复刻音色”，设备会提示从一数到二十，用产品麦克风录音；也可以在开发者页点击“用设备麦克风录音”。
   - **手机录音/上传**：在用户页点“使用手机录音”（Android 可调用系统录音器；iPhone 可用“语音备忘录”录好存到“文件”，或选择已有录音），也可以直接选择手机里的音频文件。
4. 设备录音最多 20 秒；累计至少 5 秒人声、随后停顿约 1.5 秒时可提前结束。手机录音同样限制 5～20 秒，页面转换成 16 kHz 单声道 PCM 后上传。成功创建后自动使用新音色并保留上一个声音，可试听、切回、重命名或删除。
5. 聊天中说“切换音色”，听完列表后可在 60 秒内说出名称；说“取消”保留当前声音。用户页也可以选择、重命名或删除专属音色，正在使用的音色不能直接删除。
6. 设备麦克风和手机上传两种方式共用同一个音色列表；每个入口同一时间只允许一个录音/创建任务。跨入口同时发起时可能有一方提示忙，请稍后重试。

复刻录音和试听可在页面点击取消；设备录音也可以让机身双击退出对话取消。手机录音可以随时停止。已经开始的网络请求可能要等超时才能退出，取消不等于删除云端已经创建的音色。

配置不完整时，普通聊天继续用原服务声音。复刻只更换联网聊天声音，开机、配网、关机等固定音包保留原声。

## 设备录音、手机录音和音频文件

设备麦克风录音仍保留：聊天中说“复刻音色”或开发者页点击“用设备麦克风录音”，设备会用产品麦克风采样并提交同一云端创建任务。

用户页面提供三种手机侧方式：

- 手机浏览器允许麦克风时，用“开始手机录音”；
- Android 可用“使用手机录音”调用系统录音器；
- 或先用手机录音软件（iPhone 语音备忘录）录好，保存到“文件”，再选择上传。

原始 HTTP 热点页面通常不是安全上下文，浏览器可能拒绝网页直接调用麦克风；此时优先使用手机系统录音或已有音频文件。页面在手机端把音频转换成 16 kHz 单声道 PCM，长度限制 5～20 秒，单文件不超过 20 MB；点“上传录音并创建音色”后才上传。PCM 经 HTTPS 提交阿里服务，不写入外置声音 Flash。联网回答的文本会交给该语音服务合成。

请保持手机连接设备热点；如果录音或上传期间切换了 Wi-Fi，重新连接设备热点并刷新音色列表查看结果，创建任务可能仍在设备上继续。

本设备管理列表最多保留 10 个专属音色，系统音色不计入。云端音色按设备完整 MAC 生成的固定前缀区分；中文名称保存在本机 NVS。删除会同时删除云端音色。旧公共前缀音色不自动归属或清理，更换主板、清除 NVS 或共享同一 API Key 时，应结合云端账户核对。

## 接入与兼容

- 保留参考版本的北京地域 `qwen-audio-3.1-tts-flash`、流式 SSE 合成、受限音频缓冲、音色查询和创建结果未确认保护。模型与接口见阿里官方的 [模型说明](https://help.aliyun.com/zh/model-studio/tts-model)、[复刻接口](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api) 和 [系统音色](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。
- 三款板通过可选 `Board` 接口获取服务；其他开发板默认没有此能力。公共模块不包含具体板型或其引脚配置。
- 设备麦克风录音仍走现有采样器；手机上传的 PCM 进入同一上传/创建工作任务。两种方式共用音色列表和创建预留；每个入口有忙状态，跨入口同时发起时可能提示忙。播放和试听复用唯一 AudioService 播放任务，经过现有音质、增益、保护与播放参考链路，没有新增 I2S 播放通道。
- 本地选声开始时关闭旧聊天通道，结束后在后台重连；旧回复和旧工作任务按代次隔离。新一轮继续使用既有 WebSocket 或 MQTT/UDP 协议。
- 后台重连持有协议对象，旧对象可能比主流程存活更久。协议替换或重置时单独失效其回调代次，迟到的音频、关闭和错误不能改变新会话；网络错误和连接提示回到应用任务处理。
- 原版与人声打断版分别保留。没有引入参考分支中的实验性软件 AEC；当前的播放参考、近端人声判断、首字缓存和响度保护继续生效。
- 新的 PCM 流结束后，按播放代次提交尾音排空；旧工作任务不能结束新一轮声音。配置按每轮快照使用，取消和设置失败保留已有可用配置。
- NVS 沿用参考版 `voice_tts` 命名空间，支持旧 `ali_voice` 到当前／上一音色单条记录的迁移。创建结果未确认时暂停重复创建，先刷新列表核对；不自动重发可能已经成功的创建请求。

歌曲播放仍沿用参考版本对已观察到的工具状态和结束语的识别。这些文本规则不能代替可靠的歌曲结束事件，需结合实际聊天服务验证切回音色的表现。

## 验证

构建、主机测试和浏览器检查结果见本轮 `dist/wzh-voice-clone-20261107/` 中的 `validation.json`、`console-review.json` 与各构建日志。使用当前已安装的 ESP-IDF 6.0.1；该主机尚未安装首选的 6.0.2。

主机回归 319 项通过；额外 8 项 AddressSanitizer／UndefinedBehaviorSanitizer 检查覆盖 PCM 环形缓冲、取消交接、配置迁移、名称存储、创建预留和采样转发。旧协议回调替换与正在选声时迟到的人声打断事件均有回归用例。

浏览器使用模拟设备接口，已检查三款产品桌面／手机布局、首页进入、Key 不回显、设备录音取消、手机录音/文件上传、试听取消、本地 WAV 转换上传和切回上一个音色；未调用真实云端，也未采集真实麦克风。

实机还需验证：实际服务权限与音色质量、手机录音文件转换和上传、选声、连续故事、音乐切换、音量 100、回声与人声打断、重连、断网和取消、低电与关机。构建通过不代表这些项目已验收；本轮不烧录、不创建或删除真实云端音色。
