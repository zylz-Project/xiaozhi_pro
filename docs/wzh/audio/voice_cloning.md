# 三款产品音色复刻与管理

更新：2026-11-07。已接入大熊猫、小熊猫、恐龙；软件验证和实机验收分开记录。参考 [feature/weijian-dev](https://github.com/zylz-Project/xiaozhi_pro/tree/09b07763778c91480540d44f00a68f109f6645d3)，共享实现位于 `main/boards/common/wzh/voice_tts/`。

## 怎么使用

1. 先让设备连接Wi-Fi，再访问管理页 `http://192.168.4.1:8080/`。配网页 `http://192.168.4.1/` 用于连接网络，两者用途不同。
2. 点击首页“专属音色”，用现有开发者密码解锁。在“阿里服务设置”保存北京地域的百炼API Key，选择一个系统音色。Key保存后不回显。
3. 在聊天中说“复刻音色”或“我想复刻音色”，设备会提示从一数到二十，然后用设备麦克风录音。也可以在页面填写名称，点击“用设备麦克风录音”。
4. 设备最多录20秒；累计至少5秒人声、随后停顿约1.5秒时可提前结束。录音结束后提交复刻，成功后自动使用新音色，并保留上一个声音。管理页可以试听和切回。
5. 聊天中说“切换音色”，听完列表后，在60秒内说出名称；说“取消”保留当前声音。页面也可选择、重命名或删除专属音色，正在使用的音色不能直接删除。

复刻录音和试听可在页面点击取消；机身双击退出对话也会取消设备录音或试听。已经开始的网络请求可能要等超时才能退出，取消不等于删除云端已经创建的音色。

先选系统音色，是为了让设备能用当前声音播放录音提示。配置不完整时，普通聊天继续用原服务声音。复刻只更换联网聊天声音，开机、配网、关机等固定音包保留原声。

## 网页录音和音频文件

页面支持浏览器麦克风录音，也支持选择本地音频文件。原始HTTP热点页面可能没有浏览器麦克风权限，此时优先使用设备麦克风，或通过手机系统录音后选择文件。

文件在页面转换成16kHz单声道PCM，长度限制5～20秒；点击“上传并创建音色”后才上传。设备录音也只暂存在运行内存，随后经HTTPS提交阿里服务，不写入外置声音Flash。联网回答的文本会交给该语音服务合成。

本设备管理列表最多保留10个专属音色，系统音色不计入。云端音色按设备完整MAC生成的固定前缀区分；中文名称保存在本机NVS。删除会同时删除云端音色。旧公共前缀音色不自动归属或清理，更换主板、清除NVS或共享同一API Key时，应结合云端账户核对。

## 接入与兼容

- 保留参考版本的北京地域 `qwen-audio-3.1-tts-flash`、流式SSE合成、受限音频缓冲、音色查询和创建结果未确认保护。模型与接口见阿里官方的 [模型说明](https://help.aliyun.com/zh/model-studio/tts-model)、[复刻接口](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api)和 [系统音色](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。
- 三款板通过可选 `Board` 接口获取服务；其他开发板默认没有此能力。公共模块不包含具体板型或其引脚配置。
- HTTP合成、上传和音色管理在独立工作任务执行。PCM复用唯一AudioService播放任务，经过现有音质、增益、保护与播放参考链路；没有新增I2S播放通道。
- 录音期间，本地处理后的PCM直接进入采样器，不经过聊天上传编码。暂停动作和普通唤醒，安全保护、取消与关机保留。旧人声打断事件不能取消新录音。
- 本地复刻或选声开始时关闭旧聊天通道，结束后在后台重连；旧回复和旧工作任务按代次隔离。新一轮继续使用既有WebSocket或MQTT/UDP协议。
- 后台重连持有协议对象，旧对象可能比主流程存活更久。协议替换或重置时单独失效其回调代次，迟到的音频、关闭和错误不能改变新会话；网络错误和连接提示回到应用任务处理。
- 原版与人声打断版分别保留。没有引入参考分支中的实验性软件AEC；当前的播放参考、近端人声判断、首字缓存和响度保护继续生效。
- 新的PCM流结束后，按播放代次提交尾音排空；旧工作任务不能结束新一轮声音。配置按每轮快照使用，取消和设置失败保留已有可用配置。
- NVS沿用参考版 `voice_tts` 命名空间，支持旧 `ali_voice` 到当前／上一音色单条记录的迁移。创建结果未确认时暂停重复创建，先刷新列表核对；不自动重发可能已经成功的创建请求。

歌曲播放仍沿用参考版本对已观察到的工具状态和结束语的识别。这些文本规则不能代替可靠的歌曲结束事件，需结合实际聊天服务验证切回音色的表现。

## 验证

构建、主机测试和浏览器检查结果见本轮 `dist/wzh-voice-clone-20261107/` 中的 `validation.json`、`console-review.json` 与各构建日志。使用当前已安装的ESP-IDF 6.0.1；该主机尚未安装首选的6.0.2。

主机回归319项通过；额外8项AddressSanitizer／UndefinedBehaviorSanitizer检查覆盖PCM环形缓冲、取消交接、配置迁移、名称存储、创建预留和采样转发。旧协议回调替换与正在录音时迟到的人声打断事件均有回归用例。

浏览器使用模拟设备接口，已检查三款产品桌面／手机布局、首页进入、Key不回显、设备录音取消、试听取消、本地WAV转换上传和切回上一个音色；未调用真实云端，也未采集真实麦克风。

实机还需验证：实际服务权限与音色质量、录音人声检测、连续故事、音乐切换、音量100、回声与人声打断、重连、断网和取消、低电与关机。构建通过不代表这些项目已验收；本轮不烧录、不创建或删除真实云端音色。
