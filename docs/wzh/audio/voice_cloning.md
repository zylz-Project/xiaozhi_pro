# 三款产品音色复刻与管理

大熊猫、小熊猫和恐龙共用音色服务，支持对话指令、设备麦克风录音和手机音频上传。 [共享实现](../../../main/boards/common/wzh/voice_tts/)

## 怎么使用

聊天里的复刻和切换支持常见的近义说法，例如“克隆我的声音”“帮我换个声音”；“声音”和“音色”等可互相使用。该识别由设备对服务端识别出的文字做规则匹配，要求包含声音对象和对应操作，不等同于理解所有表达；否定、解释等语句不会作为指令处理。切换指令先列出可选音色，再按提示说名称。声音转写或服务不可用时不会触发。

1. 先让设备联网。两款熊猫使用 Wi-Fi，恐龙可使用 4G 或 Wi-Fi。手机保持连接设备热点，打开用户页 `http://192.168.4.1`，输入说明书里的页面密码，进入设备详情页。三款产品都在声音区提供音色复刻。
2. 如果页面提示“语音服务未配置”，由开发者在设备局域网 IP:8080 的“音色复刻”页保存北京地域的百炼 API Key；量产机应预置 Key。Key 保存后不回显。首次未选择音色时，设备使用内置音色播报复刻提示，不会因此改写当前选声；复刻成功后才选用新音色。
3. 填写名称后，可以选两种录音方式：
   - **设备麦克风**：在聊天中说“复刻音色”或“我想复刻音色”，设备会提示从一数到二十，用产品麦克风录音；也可以在开发者页点击“用设备麦克风录音”。
   - **手机录音/上传**：在用户页点“使用手机录音”（Android 可调用系统录音器；iPhone 可用“语音备忘录”录好存到“文件”，或选择已有录音），也可以直接选择手机里的音频文件。
4. 设备录音最多 20 秒；累计至少 5 秒人声、随后停顿约 1.5 秒时可提前结束。手机录音同样限制 5～20 秒，页面转换成 16 kHz 单声道 PCM 后上传。成功创建后自动使用新音色并保留上一个声音，可试听、切回、重命名或删除。
5. 聊天中说“切换音色”，听完列表后可在 60 秒内说出名称，例如“原声”。说“取消”保留当前声音。也可以直接说“切回原声”，听到提示音后，下一轮回复使用小智服务端原声。直接切回原声无需阿里百炼 API Key。用户页也可以选择、重命名或删除专属音色，正在使用的音色不能直接删除。
6. 设备麦克风和手机上传两种方式共用同一个音色列表；每个入口同一时间只允许一个录音/创建任务。跨入口同时发起时可能有一方提示忙，请稍后重试。

三款设备的工厂 Audio Hub 固定使用 `http://192.168.1.111:9091`，地址由固件的工厂配置统一提供。设备先连接工厂 Wi-Fi，在开发者页打开「出厂 Audio Hub」并点击「连接并检查」，再在后台的「音色管理」里给这台设备写入 Key。Key 保存在设备本机，交付后设备用用户的网络直接连接百炼。[工厂 Audio Hub](http://192.168.1.111:9091)

自动发现使用同网段的 UDP 39876 广播，并校验 Audio Hub 的发现签名。后台部署的发现签名配置需要与固件一致。如果自动发现没有显示设备，先用开发者页的「连接并检查」直接发起登记。

预置和复刻音色可以在待机或对话中从页面试听。正在回复时，设备等这段回复结束再播放试听。试听时暂停收音，结束后回到原来的对话。页面会显示等待、播放和失败状态。“原声”可以通过正常对话听到。

设备网页会显示录音、上传和生成的进度。点击“停止录音”会停止本次设备麦克风采集。对话中发起的录制会恢复聆听。双击退出对话时也会取消设备麦克风录音或音色试听。已开始的云端请求可能要等到结束，已创建的音色可以在音色管理中删除。

配置不完整时，普通聊天继续用原服务声音。复刻只更换联网聊天声音，开机、配网、关机等固定音包保留原声。

收到复刻或切换命令时，设备先隔离旧回答，再根据配置启动录音或列出音色。缺少 Key 时，设备发出错误提示音，并在可用的显示和日志中给出原因。

## 手机录音和音频文件

用户页面提供三种手机侧方式：

- 手机浏览器允许麦克风时，用“开始手机录音”；
- Android 可用“使用手机录音”调用系统录音器；
- 或先用手机录音软件（iPhone 语音备忘录）录好，保存到“文件”，再选择上传。

原始 HTTP 热点页面通常不是安全上下文，浏览器可能拒绝网页直接调用麦克风；此时优先使用手机系统录音或已有音频文件。页面在手机端把音频转换成 16 kHz 单声道 PCM，长度限制 5～20 秒，单文件不超过 20 MB；点“上传录音并创建音色”后才上传。PCM 经 HTTPS 提交阿里服务，不写入外置声音 Flash。联网回答的文本会交给该语音服务合成。

请保持手机连接设备热点；如果录音或上传期间切换了 Wi-Fi，重新连接设备热点并刷新音色列表查看结果，创建任务可能仍在设备上继续。

安卓配网弹窗若点选后没有弹出文件选择器，请保持热点连接，在 Chrome 地址栏打开 `http://192.168.4.1`，进入音色复刻后再选择文件。[Android WebView 文件选择说明](https://developer.android.com/reference/android/webkit/WebChromeClient)

本设备管理列表最多保留 10 个专属音色，系统音色不计入。云端音色按设备完整 MAC 生成的固定前缀区分；中文名称保存在本机 NVS。删除会同时删除云端音色。旧公共前缀音色不自动归属或清理，更换主板、清除 NVS 或共享同一 API Key 时，应结合云端账户核对。

## 接入与兼容

- 保留参考版本的北京地域 `qwen-audio-3.1-tts-flash`、流式 SSE 合成、受限音频缓冲、音色查询和创建结果未确认保护。模型与接口见阿里官方的 [模型说明](https://help.aliyun.com/zh/model-studio/tts-model)、[复刻接口](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api) 和 [系统音色](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。
- 三款板通过可选 `Board` 接口获取服务；其他开发板默认没有此能力。公共模块不包含具体板型或其引脚配置。
- 设备麦克风录音仍走现有采样器；手机上传的 PCM 进入同一上传/创建工作任务。两种方式共用音色列表和创建预留；每个入口有忙状态，跨入口同时发起时可能提示忙。播放和试听复用唯一 AudioService 播放任务，经过现有音质、增益、保护与播放参考链路，没有新增 I2S 播放通道。
- 本地选声开始时关闭旧聊天通道，结束后在后台重连；旧回复和旧工作任务按代次隔离。新一轮继续使用既有 WebSocket 或 MQTT/UDP 协议。
- 后台重连持有协议对象，旧对象可能比主流程存活更久。协议替换或重置时单独失效其回调代次，迟到的音频、关闭和错误不能改变新会话；网络错误和连接提示回到应用任务处理。
- Wi-Fi 合成播放使用 24 kHz PCM，恐龙 4G 使用经 ML307 AT 传输的 Ogg/Opus。两种路径复用同一扬声器任务。 [恐龙 4G 与验收](../hardware/dinosaur_ml307_2026-11-15.md)
- 恐龙 4G 若只有一个不超过 36 字节的片段且尚未收到本轮结束，允许从入队起最多等 1.8 秒，减少重复 HTTPS 请求造成的句间停顿。收到下一段或本轮结束会立即重新检查。上一笔合成占用的排队时间计入等待窗口。启用串口日志时，`text_queue_ms` 记录最早的文本片段从入队到被取出的时间，`Ali first Opus packet` 记录发起合成到收到首个音频包的耗时。
- 新的 PCM 流结束后，按播放代次提交尾音排空；旧工作任务不能结束新一轮声音。配置按每轮快照使用，取消和设置失败保留已有可用配置。
- NVS 沿用参考版 `voice_tts` 命名空间，支持旧 `ali_voice` 到当前／上一音色单条记录的迁移。创建结果未确认时暂停重复创建，先刷新列表核对；不自动重发可能已经成功的创建请求。

歌曲播放仍沿用参考版本对已观察到的工具状态和结束语的识别。这些文本规则不能代替可靠的歌曲结束事件，需结合实际聊天服务验证切回音色的表现。

## 验证

主机测试覆盖采集转发、配置迁移、创建预留、TTS 缓冲、取消交接和晚到回复隔离。实机按三款分别检查实际百炼权限、普通话录音、Android 和 iPhone 文件上传、改名、切换、取消、音乐切回、连续回复与弱网。恐龙另测 4G 连续合成、网络切换和恢复。 [整机验收](../product/product_acceptance.md)
