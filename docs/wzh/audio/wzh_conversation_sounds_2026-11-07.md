# WZH 进入／退出对话提示音（2026-11-07）

大熊猫、小熊猫和恐龙现在均区分进入、退出对话的音效，普通版与 `-barge-in` 版均适用。此前两种操作都会播放同一段 `popup.ogg`。

| 操作 | 音效 | 离线解码时长 |
| --- | --- | ---: |
| 进入对话 | 保留原 `main/assets/common/popup.ogg` | 约 0.48 秒 |
| 主动退出对话 | 新 `main/assets/wzh_sounds/conversation_exit.ogg`，784 Hz → 440 Hz 下降双音 | 约 0.36 秒 |

三款使用同一套进入／退出提示规则。退出音是本地生成的短音效，不需要联网或额外烧写外置音频 Flash，也没有替换已有的语音播报。源脚本为 `scripts/audio/build_wzh_conversation_sound.py`，使用 Python 标准库和 ffmpeg 生成单声道 Ogg/Opus（60 ms 帧），软起音与软收尾。数字解码检查的有效信号 RMS：进入 -14.88 dBFS、退出 -14.93 dBFS；新退出音峰值 -10.40 dBFS，没有 int16 削顶。以上不代表实机听感验收。

## 接入与取消规则

- `Board` 增加可选 `GetConversationExitSound()`；三个 WZH 板返回同一个固件内置退出音。其他板默认返回空，沿用原提示。核心只依赖 `Board` 接口。
- 新资源只在 WZH 分支通过 CMake 嵌入；公共 WZH 模块返回静态 `string_view`，不创建播放器、解码器或任务。所有声音仍由唯一 `AudioService` 输出。
- 进入提示保留现有的主任务／采集初始化时序；主动退出在主任务停止旧回复并清队列后播放退出音，再进入 Idle。Connecting、Listening 和 Speaking 都覆盖。
- 会话代次检查在播放之前执行；已失效的旧退出请求不能把声音排入新会话。已经 Idle 时不重复退出音。`StopInteraction()` 默认的停止／休息／安静／关机调用不在此额外播放提示。
- 本轮不改变按键规则、音量、引脚、NVS、唤醒模型、人声打断或传输协议。
