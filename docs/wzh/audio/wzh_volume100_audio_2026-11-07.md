# WZH 音量 100 破音：调研、修正与自审（2026-11-07）

用户反馈音量为 100 时音质特别差。本轮先核对原理图、器件手册与当前驱动，再实施增益修正。适用于三款 WZH 的普通版和人声打断版；没有把编译通过当作实机音质验收。

## 调研结论

**发现一项明确的硬件增益配置遗漏：NS4150 的实际增益为 20dB，代码却按 0dB 配置。** 这是最高音量容易过驱的直接风险，实际失真的全部来源仍需样机确认。

1. 重新检查《V4-2.2小熊猫-改.pdf》第 5 页：NS4150 的 R35、R37 均为 30kΩ，VCC 经 R36=2Ω 接 3.3V。PDF SHA-256 为 `8524f8abcf929897cc4104a1645b688b7a437ac00da02710a6e0b5ca0916df45`，与既有硬件复核使用的图纸一致。
2. [NS4150 厂家手册 §9.9](https://dl.espressif.com/dl/schematics/NS4150B.pdf) 给出 `Av = 300k / Rin`。因此当前电路为 10 倍，即 `20 × log10(10) = 20dB`。手册中的高功率指标有具体电压、负载与 THD 条件，不能直接作为本板 3.3V 条件下的低失真功率保证。
3. [乐鑫 esp_codec_dev 1.5.10 的音量说明](https://components.espressif.com/components/espressif/esp_codec_dev/versions/1.5.10/readme) 定义 1～100 对应 -49.5～0dB，0 为静音；硬件功放增益还需单独提供。当前仓库恰为该版本，本轮也读取了本地实现：`hw_gain = 20*log10(Vdac/Vpa) + pa_gain`，写入 ES8311 的 DAC 目标为音量曲线值减去 `hw_gain`。
4. 当前固件已经修正过 Vpa=3.3V，但 `es8311_cfg` 清零后从未填写 `hw_gain.pa_gain`，所以仍漏算 20dB。音量 100 实际写入 DAC 0dB，然后再经外部 10 倍放大；数字 PCM 未达到 int16 满幅也不能排除模拟功放削顶。
5. [乐鑫音频电路说明](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s2/esp32-s2-hmi-devkit-1/reference/audio.html) 同样强调匹配 DAC、功放增益和供电摆幅来减少饱和。该开发板的具体增益与供电不同，本轮没有照搬其硬件参数。

此前官方音乐约 27.4 kbps 的音源限制仍然存在，见[音乐实机反馈](../archive/2026-11/wzh_tailredpanda_music_feedback_2026-11-04.md)。本轮针对“音量升到 100 明显恶化”的增益路径，没有通过改上行码率、提高名义采样率或再次叠加 EQ 来声称恢复音源细节。

## 实施

- 三款 `config.h` 新增实物电路参数 `AUDIO_CODEC_PA_GAIN_DB=20.0f`，板级构造唯一 ES8311 时传入；引脚与供电参数不变。
- 共享 ES8311 构造器新增可选 `pa_gain_db` 和 `max_output_volume_db`，默认均为 0，原有调用方保留原映射；WZH 的功放增益进入驱动原有补偿公式。
- WZH 设置最高目标为 -3dB。曲线点为 `(0,-50)`、`(80,-10)`、`(100,-3)`；音量 0 继续使用驱动原有 -96dB 静音规则。额外 3dB 是为供电串联电阻、电源压降和器件偏差保留的初始余量，仍需按实机响度／失真测量确认。
- 曲线在每次设备创建／重新打开后、恢复用户音量之前重新设置，避免休眠重开后丢失限制。底层 API 复制曲线数据；没有每帧分配，也没有新建音频任务。设置音量时夹到 0～100，页面和 NVS 仍保存用户选值。
- 保留已有高通、EQ、RMS 保护、限幅、24 kHz 时钟和单一输出路径；TTS、音乐、本地声音与系统提示都使用修正后的 DAC 增益。输入增益、M/R 参考采集、AEC/VAD、协议及队列规则不改。

### 音量数值与响度的变化

**同一音量数值下会变轻，尤其是 100；这是本轮主动减少过驱的结果。** 1～80 的目标曲线形状保留，但真实 DAC 增益因补齐功放补偿而减少 20dB；81～100 还逐步加入最多 3dB 余量。不能描述为“音量完全不变”。

| UI 音量 | 旧 DAC 目标 | 新 DAC 目标 | 新 ES8311 0x32 |
| ---: | ---: | ---: | ---: |
| 0 | 静音 | 静音 | 0x00 |
| 70 | -15dB | -35dB | 0x79 |
| 80 | -10dB | -30dB | 0x83 |
| 90 | -5dB | -26.5dB | 0x8A |
| 100 | 0dB | -23dB | 0x91 |

表中的增益差是驱动设置的差异，不能等同于实测声压差：旧版可能已被模拟削顶压住。新的最大目标也不是已标定的扬声器安全功率；目前没有本机扬声器阻抗／额定功率、满音量供电波形或 THD 实测。如果实机声音偏小，应测量后调整最大目标或供电／输入电阻，不能直接恢复遗漏的功放增益配置。

## 实机验收

本轮没有烧录、测量真实 THD 或宣称音质已经验收。需要三款分别在 70／80／90／100 下对照相同 TTS、本地录音、提示音和音乐，检查响度、破音、长播发热、机身共振及退出收尾。记录有／无舵机动作与相近电池状态下的表现；音频相关回归还包括录音、待机唤醒、VAD、人声打断、静音恢复、重连及当前 AEC 模式。

若仍破音，应优先测 NS4150 VCC、R36 两端和桥接扬声器的差分输出，确认实装 R35/R37、负载、腔体及音源；目前的软件结果不足以区分这些剩余因素。
