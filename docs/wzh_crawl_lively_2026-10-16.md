# 爬爬熊猫整套灵动编舞

日期：2026-10-16。本轮专门修改爬爬熊猫，在上一轮快速动作基础上重新编排全部动作。其他两款保留[上一轮固件](../dist/wzh-fast-motion-20261016/README.md)。

## 本轮完成的内容

保留 33 个完整表演、8 个身体指令、33 个互动回应，共 74 个动作入口；重写 73 组独立关键帧数组、408 个姿态点，交替爬行与身体爬行入口共用同一组素材。所有入口名称、GPIO、默认位和机械限位保持原有含义。

此前很多回应只动头部，或者一个姿态停住后回中。本轮让多数回应包含观察、伸爪、换边、再次回应和收势。普通编舞中头部先带动作，前爪按不同节拍跟上；连续关键帧连接处保持位置和速度连续，节拍变形在边界的二阶导数也归零。

正常模式逐项输出回放中，头部与双前爪行程均达到 35° 的动作从 **37 个增加到 71 个**。另外 3 个是明确的“摇头／看左／看右”，保留只动头部，避免把单部位指令变成额外的身体动作。

这 71 个动作进一步要求头部总行程至少 50°、每只前爪至少 35°。全部动作在请求开始后的前 240ms 内至少一路累计偏移达到 10°；33 个温和互动回应同样检查了可见行程。这里的时间从动作开始算，实物还包含传感器消抖、调度和舵机响应。

## 互动时看到什么

下列是三套变化的编舞主题，不是新增语音词表。每类互动仍独立洗牌，连续选择不会重复上一套。

| 事件 | 三套回应的变化 |
| --- | --- |
| 触摸1 | 回看招呼；从另一侧回看伸爪；观察后双爪回应 |
| 触摸2 | 左爪伸出再收回；左爪二次招呼；左爪带头、另一爪跟随 |
| 触摸3 | 右爪伸出再收回；右爪二次招呼；右爪带头、另一爪跟随 |
| 触摸4 | 双爪亲近；另一侧展开抱抱；左右观察后双爪回应 |
| 组合／连续触摸玩耍 | 短快爬配回看；交替拍爪；左右换重心邀请玩耍 |
| 持续触摸 | 双爪靠近；另一侧靠近；回看、收爪再亲近 |
| 松手 | 伸爪挽留；另一侧挽留；换爪回应后收势 |
| 拿起 | 转头找人配双爪；另一方向观察；先观察再换爪 |
| 摇晃 | 大范围回看配交替前爪；反向回应；左右观察、换爪收势 |
| 翻面 | 收爪观察再展开；反向观察；先收起再伸爪重新确认 |
| 放稳 | 撑爪、回看、收势；另一方向确认；换爪站稳再回中 |

持续触摸、拿起／摇晃／翻面后的温和窗口继续缩幅；它们也有双前爪动作。四个触点的实际位置取决于电极安装，固件不会凭触点编号推断“头顶／肚子”等真实位置。

## 身体指令与爬行

- 摇头增加连续中间姿态，减少停住再起步；左右看保留指定方向。
- 左右挥爪保持完整行程，并加入头部观察和另一爪的配合。修正这两个具名动作可被随机镜像反转的问题。
- 举起双爪增加预备、展开、展示和收势。
- 交替爬行仍为 800ms×6、同步爬行为 1200ms×4，双臂沿用参考工程的 82° 连续轨迹，不因头部回看或说话偏移改变牵引周期。
- 爬行头部不再固定在 90°，正常模式约 30°～150° 回看，每两次手臂周期完成一次左右观察。入场加上约 24° 的短暂回看，让双手爬行不再从静止空等 400ms。
- 正常起始仍约 5.6 秒收尾，短爬行互动约 2.4 秒；从另一极值动作切入可能仅延长入场。停止／保护可以中断，结束后不自己再来一轮。

联网进入对话后可请求“爬一爬”“双手一起爬”“挥挥左手”“摇摇头”等；具体语义调用取决于在线服务。当前 12 条离线短语保持原有词表，没有新增离线爬行口令。

## 说话时的身体语言

语音随动改为每台控制器持有自己的状态：头部跟随重音，双前爪在不同相位回应，新的说话段落有方向和起始相位变化。目标经过临界阻尼跟随，避免重音直接变成角度跳变。

停止播放或超过 200ms 未更新后清除旧的跟随状态，避免下一段声音继承上一次的前爪偏移。仍只使用 AudioService 的真实输出包络，外置 Flash 保持原有录音，离线有限编舞不因长录音持续摆动。

## 验证与实物边界

123 项主机测试通过，本轮受影响的爬爬熊猫完整构建通过，使用本机 ESP-IDF v6.0.1；项目首选 v6.0.2 本机未安装。其他两款源码保持上一轮版本，主机回归仍覆盖它们。

检查覆盖全部编舞及三个模式的输出范围与有限结束、74 个动作可见反馈、33 个温和互动、左右具名动作方向、头爪错拍的连续性、语音状态恢复、计时回绕、参考爬行双臂波形，以及原有停止、保护、虚拟24小时静置和自身运动过滤。预览页已检查全部74项选择、两版／两状态、拖动时间、移动端宽度和脚本异常。

本轮没有烧录或测量玩具。新编舞需逐台验证外壳／毛绒干涉、前爪配合与地面牵引、供电跌落、真实舵机温升及自身振动误触发。GPIO、默认 90°／90°／90° 和 8°～172° 限位保持原有设置，现有保护不能直接测量舵机堵转电流或温度。
