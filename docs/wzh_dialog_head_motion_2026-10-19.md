# 对话头部随动增强（2026-10-19）

针对实机观感“对话时动作幅度不够、偏慢，头部不够灵活”，本轮只调整语音随动层，不改动作库、音频配对、机械限位、对话协议和双击控制。

## 调整内容

| 项目 | 调整前 | 调整后 |
|---|---|---|
| 语音能量映射 | `sqrt(level × 2.6)` | `sqrt(level × 3.8)`，正常说话更接近完整手势 |
| 头部摆幅（熊猫两款） | 76° / 74° 目标 | **82°**，接近机械可用行程 |
| 恐龙头部转向 | 78° 目标 | **90°**，配合颈侧倾与尾部反向 |
| 头部连续摆动 | 只在节拍切换时动 | 约 **1 Hz** 连续摆动，正常语音约 9～13° |
| 重音点头 | 仅整体放大 12% | 额外 **6°** 同向点头，强调重音 |
| 阻尼响应 | ω=11（熊猫）/7（恐龙） | **13.5 / 9.5**，头部轴再 ×1.2 |
| 速度上限 | 280°/s / 100°/s | **360°/s / 220°/s** |
| 语句周期 | 3.0～4.4 秒 | **2.4～3.5 秒**，换姿态更勤 |
| 第四拍收势 | 保留 18% | 保留 **32%**，减少长时间“停住” |
| 重音强调 | 12% | **20%** |
| 电平平滑 | 10 / 6 | **15 / 9**，起音更快、收尾仍平滑 |

- 安静、安慰、晚安仍会更柔和；睡眠意图继续乘 0.45。
- 实际无声后 220 ms 内收势，关节回到 0；不会在停顿里继续摆头。
- 原有机械夹紧、最终 400°/s 输出限速、保护、停止/归中和舵机断电逻辑不变。

## 软件实测

用当前 `VoiceMotion` 在典型语音电平下回放 60 秒，头部（恐龙取头转向轴）软件目标摆幅：

| 产品 | 电平 0.15 | 电平 0.30 |
|---|---:|---:|
| 大熊猫 | 155.8° | 164.0° |
| 小熊猫 | 155.8° | 164.0° |
| 恐龙 | 166.1° | 179.7° |

头部换向约 2 次/秒（熊猫）和 1.5 次/秒（恐龙），比原来只在节拍边界变化更连续。以上是舵机命令目标，不是负载下的实际角度。

## 实机注意

- 熊猫头部目标已接近 ±82° 机械行程，恐龙头部转向接近 ±90°；连续大幅摆头会更频繁地接近限位，需确认毛绒/机构不干涉、舵机电流和温度可接受。
- 恐龙速度从 100°/s 提到 220°/s，颈部负载较大；如果实机出现抖动、丢步或电流偏高，可单独把恐龙降回 160～180°/s。
- 本轮未烧录、未做真实云端对话验收；软件轨迹通过不代表负载下效果。建议先试听一段较长的云端回复，观察头部是否自然、是否频繁顶住限位。
