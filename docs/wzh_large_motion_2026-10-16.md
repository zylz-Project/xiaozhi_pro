## 实际修改

| 项目 | 原实现 | 当前实现 |
| --- | --- | --- |
| 两款熊猫的关键帧 | 相对默认姿态放大 1.25 倍 | 放大 1.60 倍，最终仍经过各轴限位 |
| 熊猫轻触回应 | 两关键帧，幅度偏小，到达后立即回程 | 扩大目标行程，增加约 420ms 的明确到位停留，再回默认姿态 |
| 摇尾小熊猫播放器 | 后 30% 帧时间提前转向下一目标，并叠加指数追踪 | 从当前姿态做五次缓动，到达本帧目标后再切换，避免目标在追到之前消失 |
| 熊猫移动时间 | 以 1.5 倍平均速度估算峰值 | 根据五次缓动的 1.875 倍峰值安排时长，保留最终 80°/s 输出限速 |
| 三款温和模式 | 普通偏移的 35% | 调整到 60%，被抱起时仍比正常模式温和，但保持可见动作 |
| 恐龙普通表演 | 1.12～1.22 倍幅度 | 1.35～1.50 倍；短声音强制剪辑 1.40 倍，怒吼剪辑 1.15 倍 |
| 恐龙身体指令 | 固定 1.0 倍，部分头/尾行程较小 | 固定 1.40 倍，并扩大摇头、抬低头、摆尾和扭颈的关键帧 |
| 恐龙颈俯仰放大中心 | 与其他轴一律按 90° 放大 | 按实际默认 70° 放大，保留明确的 0°/180° 仰头/取食目标 |
| 三款声音随动 | 重音偏移小、衰减快 | 增加低频头部/肢体/尾巴幅度，放缓重音衰减；最终仍限位、限速 |
| 动作中加速度事件 | 自身摆动可能被当作拿起/放稳，抢占动作并进入温和缩幅 | 当前动作执行时拒绝新的拿起/放稳请求；摇晃、翻面及独立落体保护仍有效。拒绝的事件不再提前修改温和状态 |

增加每约 500ms 的 `Servo command` 日志，显示实际提交给 PWM 的目标角度、温和状态和保护位。
这些数值是软件指令，不是舵机位置传感器反馈。

## 爬爬熊猫的可见行程

正常模式、没有新输入或保护打断时：

| 输入 | 当前主要动作目标 |
| --- | --- |
| SW1 | 头部 90° → 172°，停留后回中 |
| SW2 | 左前肢 90° → 8°，停留后回中 |
| SW3 | 右前肢 90° → 172°，停留后回中 |
| SW4 | 左前肢到 8°、右前肢到 172°，停留后回中 |
| 同一触点三次轻触，或组合触摸 | 一轮交替扒动后收回 |
| 长按/拿起等温和回应 | 使用扩大后的动作，按 60% 偏移输出；保留温和控制 |

上表的 SW1～SW4 是软件编号，具体触点装在身体哪里仍以实物接线为准。
长按约 1.2 秒会切换到温和回应，因此验收单点大幅动作时先轻触并松手。

小熊猫的单触点与姿态回应也增加行程，并包含明确的转头/摆尾/抬尾组合；默认尾上下保持 150°。

## 从 test_crawl 接入的爬行

参考代码：`/home/wzh/program/ESP32/zylz_project/test_crawl/main/auto_run.cc`，以及 `config.h` 的爬行参数。
参考工程通过连续余弦轨迹做 82° 扒动，左臂 IO15 从 90° 向 8°，右臂 IO16 从 90° 向 172°，支持交替和同步模式。

本工程移植其方向、有效行程与两种步态，适配现有关键帧引擎，使用有限轮次、缓动与到位停留。
没有复制测试工程的开机连续循环、无限 Web 任务、800/1200ms 快速周期或固定网络配置。
当前按已有速度限制延长移动时间，让完整 82° 行程真正输出，避免快速波形被限速压成小幅摆动。

| 入口 | 行为 |
| --- | --- |
| 本地触摸：同一点连续三次轻触或组合触摸 | 正常模式给一轮交替爬行；温和/安静状态保持较温和的双臂回应 |
| 原有离线口令“开心” | 正常、本地、明确请求时执行两轮交替扒动；其他情绪回应保留对应动作族 |
| 在线说“爬一爬”“向前爬”“爬过来” | 两轮交替扒动 |
| 在线说“双手一起爬”“同步爬行” | 两轮同步扒动 |
| MCP `self.panda.body`，`action="crawl"` | 两轮交替扒动 |
| MCP `self.panda.body`，`action="crawl_both"` | 两轮同步扒动 |
| “停下”“别动”或在线转写中的“别爬/不要爬” | 取消动作和声音，释放舵机 |

“爬一爬”等新短语没有加入 MultiNet 离线词表；完全离线时可用触摸或已有“开心”口令触发。
在线文字规则和工具调用受实际语音服务影响。当前没有新增自主导航、避障或距离控制。
实际向前位移取决于机构、脚底、舵机力度和地面，软件轨迹通过不能证明样机一定能向前爬。

## 保留的约束

硬件引脚、板型标识、50Hz PWM、三款轴方向与默认姿态保持原定义。
熊猫仍受 80°/s 输出限制；恐龙保留原有 80°/s 平均段速与 120°/s 最终输出限制。
大行程会相应延长回应时间，不通过提高 PWM 频率或取消缓动来放大动作。

欠压、芯片过热、落体、持续通电预算、500ms 运动更新看门狗、停止/休息和维护禁动继续有效。
没有增加定时随机表演；声音继续读取外置 Flash，在线对话仍保持语音优先。
装配诊断 `test_servo` 保留温和的小范围测试，不作为宠物大幅表演入口。

## 验证及样机检查

93 项主机测试通过，新增测试提取真实控制器的插值和最终输出函数：

- 两款熊猫全部普通、身体和互动剪辑在正常、温和、安静状态下的实际角度输出，检查行程到达、限位、限速及有限结束。
- 恐龙各剪辑族和镜像的目标解析与真实输出，检查正确的 70° 中心、0°/180° 语义极值、尾上下限位和中断。
- 交替/同步步态能输出左臂 8°、右臂 172°，方向不反转；语音和 MCP 名称映射及否定停止。
- 自身动作不会通过拿起/放稳请求缩幅；拒绝事件不改变状态，明显摇晃仍可提交回应。
- 既有 24 小时虚拟等待、声音来源/取消、唤醒及保护测试。

构建与新镜像见[本次固件](../dist/wzh-large-motion-20261016/README.md)。
本轮未执行烧录或样机验收。大幅动作的机械干涉、电流、实际舵机行程与爬行牵引力，必须用装配完整的样机确认。

烧录后先轻触 SW1～SW4 并松手，观察 `Interaction`、`clip`、`Servo command` 三类日志。
例如爬爬熊猫轻触 SW2 后应看到左臂角度明显从 90° 降低，接近 8° 并停留，再返回；若日志角度已明显变化而实物仍不动，应继续检查供电、舵盘、连杆和舵机执行情况。
